# 還款

## 什麼是還款？

還款記下的是一件事：某個人真的把錢轉給了另一個人。記錄之後：

- 這筆轉帳會納入餘額計算，抵銷兩人之間的欠款
- 支出的歷史紀錄**完全不受影響**，帳目仍然完整保留

> 記還款和刪除支出是兩回事。刪除支出是撤銷一筆支出（當作沒發生過）；還款是記錄一筆「錢已經還了」的事實。想讓餘額歸零，記還款，不要刪支出。

---

## 方法一：按「標記已還」（最快）

1. 在 Mini App 或網頁版開啟群組主頁
2. 到「**待還款**」區塊，找到你要確認的那一筆
3. 點右下角的「**標記已還**」按鈕
4. 跳出「確認 A 已還 B？」對話框，核對金額後按「**記一筆還款**」

系統會用還款建議上的金額與群組預設貨幣自動建立一筆還款紀錄，餘額立刻更新，同時在 Telegram 群組貼出一則「**💸 還款　金額**」、下一行「A → B」的訊息，讓其他人也看得到這筆錢已經還了。

---

## 方法二：手動新增

適合**部分還款**（例如只先還一半）、**不同幣別**的還款，或是用現金、其他轉帳方式付掉的款項。

在群組主頁「紀錄」區塊右上角點「**＋ 還款**」，填寫這些欄位：

| 欄位               | 說明                                   |
| ------------------ | -------------------------------------- |
| 付款人（誰轉帳）   | 欠錢、實際把錢轉出去的人               |
| 收款人（誰收到錢） | 被欠錢、收到款項的人                   |
| 金額               | 實際轉了多少                           |
| 幣別               | 這筆還款用的貨幣，預設為群組的預設貨幣 |
| 匯率               | 只有幣別和群組預設貨幣不同時才出現     |
| 日期               | 轉帳日期，預設今天                     |

付款人和收款人不能是同一個人。

## 查看與管理還款

還款**就顯示在群組主頁的「紀錄」清單裡**，和支出混在一起依時間排序，長得像「A → B」並帶一個還款圖示（手拿錢幣）。沒有另外的還款頁面。

點任一筆還款進去就是「編輯還款」頁，可以**修改**任何欄位，或按「**刪除**」整筆移除。改動會同步反映到群組裡那則「💸 還款」訊息上（詳見[記帳](/help/adding-expenses)裡的「每筆紀錄在群組裡都有一則訊息」）。

群組裡的還款訊息本身也有兩顆按鈕：「**App 編輯**」和「**⊗ 刪除**」。

**群組裡的任何成員都可以編輯或刪除還款**，規則和支出相同，見[記帳](/help/adding-expenses#修改或刪除)。

> 清單沒有「只看還款」的篩選，但還款有還款圖示和 A → B 樣式，很容易一眼認出來。只想看最近的幾筆，也可以在群組打 `/list`，還款會顯示成「💸 A → B」。

## 常見問題

**按「標記已還」按錯了怎麼辦？**

在群組主頁的「紀錄」清單裡找到那一筆還款（A → B 樣式），點進去修改金額，或直接刪除。不需要新增一筆反方向的紀錄來抵銷。

**記了還款之後餘額沒有歸零，正常嗎？**

正常。通常是因為只還了部分金額，或是還有其他支出尚未結清。把所有建議的還款都記錄完，餘額才會歸零。

**可以用不同幣別還款嗎？**

可以。手動新增時選擇實際轉帳用的幣別即可。若幣別和群組預設貨幣不同，表單會多出「匯率」欄位讓你確認或改寫換算匯率。

**全部結清後會怎樣？**

群組主頁會顯示「**所有帳款已結清**」，紀錄都還在，見[查看帳務](/help/balances#全部結清時)。
