# 結清

## 結清是什麼？

結清（Settlement）是一筆**還款記錄**，代表某人已經把錢轉給另一人。記錄結清後：

- 系統會把這筆轉帳納入帳目，更新兩人之間的餘額
- 費用的歷史記錄**不會被刪除**，帳目完整保留

> 結清和刪除費用完全不同。刪除費用是撤銷一筆支出；結清是記錄一筆「錢已還清」的事實。

---

## 怎麼記錄結清？

### 方法一：Mini App「已轉」按鈕（推薦）

1. 開啟 Mini App，進入群組主頁
2. 在「**To Settle**」區塊找到你要確認的那筆
3. 點「**已轉**」按鈕
4. 確認後，系統自動記錄這筆還款，餘額即時更新

### 方法二：手動新增還款記錄

在 Mini App 進入群組 → 點「**還款記錄**」→「**＋ 新增**」，手動填寫：

| 欄位 | 說明 |
| --- | --- |
| 付款人 | 誰轉帳（欠錢的人） |
| 收款人 | 誰收到錢（被欠的人） |
| 金額 | 實際轉了多少 |
| 幣別 | 這筆還款使用的貨幣 |
| 日期 | 轉帳日期（預設今天） |

這個方式適合**部分還款**（例如只還一半）或**Bot 以外**的還款方式（現金、Line Pay 等）。

---

## 查看與管理還款記錄

在 Mini App 點「**還款記錄**」，可以看到所有已記錄的還款，依月份排列，顯示付款人、收款人、金額（含幣別）與日期。

點開任一筆還款記錄，可以**編輯**或**刪除**——記錯金額、日期，或整筆是手誤新增的，都能直接修正，不需要用反向記錄抵銷。

---

## 常見問題

**結清後餘額沒歸零，正常嗎？**

正常。這通常表示你只記了部分還款，或還有其他費用尚未結清。完整結清後餘額才會歸零。

**按「已轉」按錯了怎麼辦？**

到「還款記錄」找到那一筆，點開後選擇「編輯」修改金額，或直接「刪除」。

**全部結清後會怎樣？**

Mini App 主頁的「To Settle」區塊會改顯示「所有帳款已結清」，並提供連結到還款記錄和統計。
