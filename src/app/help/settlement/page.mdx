# 結清

## 結清是什麼？

結清就是記下一筆**還款**——某個人真的把錢轉給了另一個人。記錄之後：

- 這筆轉帳會納入餘額計算，抵銷兩人之間的欠款
- 費用的歷史記錄**完全不受影響**，帳目仍然完整保留

> 結清和刪除費用是兩回事。刪除費用是撤銷一筆支出（當作沒發生過）；結清是記錄一筆「錢已經還了」的事實。想讓餘額歸零，用結清，不要刪費用。

---

## 方法一：按「已轉」（最快）

1. 在 Mini App 或網頁版開啟群組主頁
2. 到「**To Settle**」區塊，找到你要確認的那一筆
3. 點右下角的「**已轉**」按鈕
4. 跳出「確認已轉帳」對話框，核對金額後按「**已完成**」

系統會用還款建議上的金額與群組預設貨幣自動建立一筆還款記錄，餘額立刻更新，同時在 Telegram 群組貼出一則「**💸 A → B　金額**」的訊息，讓其他人也看得到這筆錢已經還了。

---

## 方法二：手動新增

適合**部分還款**（例如只先還一半）、**不同幣別**的還款，或是用現金、其他轉帳方式付掉的款項。

在群組主頁 Expenses 區塊右上角點「**＋ 還款**」，填寫這些欄位：

| 欄位 | 說明 |
| --- | --- |
| 付款人（誰轉帳） | 欠錢、實際把錢轉出去的人 |
| 收款人（誰收到錢） | 被欠錢、收到款項的人 |
| 金額 | 實際轉了多少 |
| 幣別 | 這筆還款用的貨幣，預設為群組的預設貨幣 |
| 匯率 | 只有幣別和群組預設貨幣不同時才出現 |
| 日期 | 轉帳日期，預設今天 |

付款人和收款人不能是同一個人。

## 查看與管理還款

還款**就顯示在群組主頁的 Expenses 清單裡**，和費用混在一起依時間排序，長得像「A → B」並帶一個 🤝 圖示。沒有另外的「還款記錄」頁面。

點任一筆還款進去就是「編輯還款記錄」頁，可以**修改**任何欄位，或按「**刪除**」整筆移除。改動會同步反映到群組裡那則「💸 A → B」訊息上（詳見[記帳](/help/adding-expenses)裡的「每筆紀錄在群組裡都有一則訊息」）。

群組裡的還款訊息本身也有兩顆按鈕：「**🔗 App 編輯**」和「**🗑 刪除**」。

**群組裡的任何成員都可以編輯或刪除還款**，和費用一樣沒有身分限制。刪除按鈕旁邊會標示「**由 X 記錄**」，刪除別人記的還款時，確認對話框也會寫明是誰記的。

> 想只看還款、不看費用？把清單上方的「只看我的」和「總額／淨額」搭配著用，或直接用日期找——還款在清單裡有明顯的 🤝 圖示和 A → B 樣式，很容易一眼認出來。

## 常見問題

**按「已轉」按錯了怎麼辦？**

在群組主頁的 Expenses 清單裡找到那一筆還款（A → B 樣式），點進去修改金額，或直接刪除。不需要新增一筆反方向的記錄來抵銷。

**結清之後餘額沒有歸零，正常嗎？**

正常。通常是因為只還了部分金額，或是還有其他費用尚未結清。把所有建議的轉帳都記錄完，餘額才會歸零。

**可以用不同幣別還款嗎？**

可以。手動新增時選擇實際轉帳用的幣別即可。若幣別和群組預設貨幣不同，表單會多出「匯率」欄位讓你確認或改寫換算匯率。

**全部結清後會怎樣？**

群組主頁的 Balance 與 To Settle 區塊會收起來，改顯示一塊綠色的「**所有帳款已結清**」，並附上「統計」的連結。已經記過的費用與還款仍然完整留在下方的 Expenses 清單裡。
