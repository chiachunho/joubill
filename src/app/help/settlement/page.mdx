# 結清

## 結清是什麼？

結清就是記下一筆**還款**——某個人真的把錢轉給了另一個人。記錄之後：

- 這筆轉帳會納入餘額計算，抵銷兩人之間的欠款
- 費用的歷史記錄**完全不受影響**，帳目仍然完整保留

> 結清和刪除費用是兩回事。刪除費用是撤銷一筆支出（當作沒發生過）；結清是記錄一筆「錢已經還了」的事實。想讓餘額歸零，用結清，不要刪費用。

---

## 方法一：按「已轉」（最快）

1. 在 Mini App 或網頁版開啟群組主頁
2. 到「**To Settle**」區塊，找到你要確認的那一筆
3. 點右下角的「**已轉**」按鈕
4. 跳出「確認已轉帳」對話框，核對金額後按「**已完成**」

系統會用還款建議上的金額與群組預設貨幣自動建立一筆還款記錄，餘額立刻更新。

---

## 方法二：手動新增

適合**部分還款**（例如只先還一半）、**不同幣別**的還款，或是用現金、其他轉帳方式付掉的款項。

進入群組 →「**還款記錄**」→ 右上角「**＋ 新增**」，填寫這些欄位：

| 欄位 | 說明 |
| --- | --- |
| 付款人（誰轉帳） | 欠錢、實際把錢轉出去的人 |
| 收款人（誰收到錢） | 被欠錢、收到款項的人 |
| 金額 | 實際轉了多少 |
| 幣別 | 這筆還款用的貨幣，預設為群組的預設貨幣 |
| 日期 | 轉帳日期，預設今天；外幣會用這天的匯率換算 |

付款人和收款人不能是同一個人。

---

## 查看與管理還款記錄

點「**還款記錄**」可以看到所有已記錄的還款，依月份分組、由新到舊，每一列顯示付款人 → 收款人、金額與幣別、日期。還沒有任何記錄時會顯示「尚無還款記錄」。

點任一筆進去就是「編輯還款記錄」頁，可以**修改**任何欄位，或按「**刪除**」整筆移除。群組裡的任何成員都可以編輯或刪除還款記錄。

---

## 常見問題

**按「已轉」按錯了怎麼辦？**

到「還款記錄」找到那一筆，點進去修改金額，或直接刪除。不需要新增一筆反方向的記錄來抵銷。

**結清之後餘額沒有歸零，正常嗎？**

正常。通常是因為只還了部分金額，或是還有其他費用尚未結清。把所有建議的轉帳都記錄完，餘額才會歸零。

**可以用不同幣別還款嗎？**

可以。手動新增時選擇實際轉帳用的幣別即可，系統會用還款日期的匯率換算後計入餘額。

**全部結清後會怎樣？**

群組主頁的 Balance 與 To Settle 區塊會收起來，改顯示「**所有帳款已結清**」，並附上「還款記錄」與「統計」的連結。
