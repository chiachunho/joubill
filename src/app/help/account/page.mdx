# 登入與帳號

揪帳有兩個介面：Telegram 裡的 **Mini App**，以及用瀏覽器打開的**網頁版**。兩邊是同一個帳號、同一份資料。這一頁講怎麼登入、怎麼把不同的登入方式連到同一個帳號，以及個人設定。

---

## Mini App 和網頁版

除了 Telegram 裡的 Mini App，揪帳也能直接用瀏覽器打開。兩邊是**同一份資料、同一套畫面**——記在 Telegram 的支出，在網頁版立刻看得到，反過來也一樣。

適合在電腦上一次整理一整趟旅程的帳，或是想用大螢幕看統計圖表的時候。

進入群組之後，兩邊的畫面與操作相同：

- 餘額、待還款、紀錄（支出與還款列表）
- 新增／編輯／刪除支出，五種分帳方式，上傳收據
- 新增／編輯／刪除還款
- 統計圖表
- 群組設定：成員管理、Telegram 群組（綁定、解除綁定、通知發送位置）、貨幣與匯率（預設貨幣、時區、自訂匯率）、動態紀錄、[匯出](/help/export)（CSV 與 beancount）、刪除群組

**返回的方式**不一樣：群組主頁左上角都是回「**我的群組**」；其他頁面在 Mini App 用 Telegram 內建的返回鍵，網頁版則是左上角的「**返回**」連結或箭頭。

另外，下面這些**只有網頁版**能做（Telegram 內建的瀏覽器做不到），在 Mini App 裡會改成「用瀏覽器開啟」：

- 下載 CSV 和 `.beancount` 檔到電腦（Mini App 可以改傳到群組或私訊）
- [加到主畫面與推播通知](/help/add-to-home-screen)
- 連結、解除連結其他登入方式，以及合併帳號
- 授權 Claude.ai、ChatGPT 等[連結的應用程式](/help/mcp)

### 我的群組

登入後的首頁會列出你參與的所有揪帳群組，每一列顯示群組頭像、名稱和該群組的預設貨幣，點進去就是這個群組的帳務主頁。

如果清單是空的，會顯示「還沒有任何群組」，並提示你可以在網頁建立群組、輸入邀請碼加入，或把機器人加進 Telegram 群組、輸入 `/start`。清單上方有「**建立群組**」和「**輸入邀請碼**」兩個入口，建立群組見[群組設定](/help/group-settings#建立群組)，輸入邀請碼見[成員](/help/members#加入群組)。

右上角的**人像圖示**可以進入個人設定。

## 登入

打開揪帳網站後會看到登入頁，可選的方式有：

- **使用 Telegram 登入**（一定有）
- **使用 LINE 登入**、**使用 GitHub 登入**、**使用 Google 登入**（視站台設定而定，沒開放時不會顯示）

> 想看到你在 Telegram 的分帳群組，請用「**使用 Telegram 登入**」。系統是用你的 Telegram 帳號來辨識身分，所以透過這個方式登入，會直接對應到 Mini App 裡的同一個你。
>
> 如果你平常只用 Telegram 使用揪帳，直接用 LINE、GitHub 或 Google 登入會是一個全新的空帳號，看不到 Telegram 群組。想換方式登入，請先連結（見下方）。

### 連結其他登入方式

在網頁版用你原本的方式登入，進到 **個人設定 → 登入方式**，點「連結 Google」（或 LINE、GitHub）並完成授權。之後用那個方式登入，看到的就是同一個帳號和同一批群組。

- 同一個登入方式只能屬於一個帳號。如果它已經屬於你的另一個帳號，會改為問你要不要把兩個帳號合併（見下方）。
- 連結沒有完成（例如在授權頁按了取消）時，會回到個人設定，在「登入方式」上方說明原因，可以直接按「再試一次」。
- 最後一個登入方式，以及 Telegram，不能解除連結。
- 如果你是先用 Google、LINE 或 GitHub 登入，也可以在同一個地方「連結 Telegram」，之後機器人和 Mini App 會認得這個帳號。如果你已經在 Telegram 用過揪帳，就會進入合併流程。
- Mini App 裡只能查看已連結的方式；要連結請用瀏覽器開啟網頁版。

### 我有兩個帳號，想合併成一個

常見的情況是：先用 Google 登入建立了一個帳號，後來才想起自己在 Telegram 早就有帳號和群組。

1. 用其中一個帳號登入網頁版。
2. 到 **個人設定 → 登入方式**，連結另一個帳號的登入方式（例如「連結 Telegram」）並完成授權。
3. 系統發現這個登入方式屬於你的另一個帳號，會打開「合併帳號」頁面。選擇要**保留**哪個帳號；系統會建議有 Telegram 的那個，或紀錄比較多的那個。
4. 確認畫面會寫出會搬走幾個群組、幾筆紀錄。按「合併」完成。

合併後：

- 兩個帳號原本的群組、帳目、付款與分攤都在保留的帳號底下，**餘額總和不變**。
- 如果兩個帳號在同一個群組，會併成一位成員，同一筆帳目上的金額會加總。
- 兩邊原本的登入方式都會登入保留的帳號；其他裝置不會被登出。
- 每個相關群組的動態都會記下這次合併。
- **合併無法還原**，被併入的帳號會消失。

要先證明兩個帳號都是你的，才能合併：你必須已經登入其中一個，並在 10 分鐘內完成另一個的登入授權。只知道別人的帳號名稱是沒辦法合併的。

在 Mini App 的 **個人設定 → 登入方式 → 合併另一個帳號** 也看得到這些步驟，按鈕會用瀏覽器打開網頁版，在那裡完成合併。

兩個帳號各自連結了**不同的** Telegram 帳號（或不同的 Google、LINE、GitHub 帳號）時無法合併，頁面會說明原因。

### 在 LINE 或 Telegram 裡打開連結

Google 不允許在 LINE、Telegram 的內建瀏覽器裡登入，這時 Google 按鈕會停用。請改用 LINE 或 Telegram 登入，或用手機瀏覽器開啟同一個網址。分享出去的邀請連結會自動要求 LINE 用外部瀏覽器開啟。

登入後會進到「我的群組」頁。

## 個人設定

點右上角的人像圖示進入「**個人設定**」，可以看到：

- 你的頭像、名稱與 username
- **登入方式**：連結其他登入方式、合併帳號（見上方）
- **連結的應用程式**：管理 MCP 連線（見[用 MCP 串接](/help/mcp)）
- **通知**、**主畫面捷徑**（見[加到主畫面與通知](/help/add-to-home-screen)）
- 「關於」區塊裡的「**使用說明**」（就是你正在看的這份文件）、「**隱私權政策**」、「**服務條款**」與**版本**號碼
- **登出**按鈕

登出後會回到登入頁。

### 改名字和頭像

- **名字**：點名字旁邊的鉛筆，輸入你想讓大家看到的名字（最多 32 個字）。所有群組、App 和機器人的新訊息都會用這個名字。留空或按「改回原本的名字」，就會用登入方式提供的名字，並跟著 Telegram 自動更新。
- **頭像**：連結了兩個以上有頭像的登入方式時，頭像右下角會有鉛筆，點頭像就能選要用哪一個（例如 Google 或 LINE 的頭像）。選「自動」會先用 Telegram 的照片，沒有的話用其他登入方式的頭像。如果解除連結的正是目前用的那個，會自動回到「自動」。

改名之前已經送出的聊天室訊息和活動紀錄會保留當時的名字。同一個群組裡如果有人取了一樣的名字，選人的選單會在後面加上原本的名字或編號來區分。

> Mini App 也有同一頁個人設定（「我的群組」頁右上角的人像圖示），一樣可以改名字和頭像，但沒有登出按鈕——在 Telegram 裡的身分是由 Telegram 本身提供的，不需要也無法登出。

## 常見問題

**網頁版可以建立新的分帳群組嗎？**

可以。在「我的群組」按「建立群組」即可，朋友用連結或邀請碼加入。這種群組沒有 Telegram 聊天室，所以不會在聊天室裡發訊息。細節請見[群組設定](/help/group-settings#建立群組)。

**在網頁版做的修改，Telegram 那邊看得到嗎？**

看得到，兩邊是同一個資料庫。重新整理或重新開啟 Mini App 就會是最新狀態。

**用 Telegram 登入網頁版之後，Mini App 會被登出嗎？**

不會。兩者互相獨立，可以同時使用。

**可以把網頁版放到手機桌面嗎？**

可以，而且不用下載。步驟見 [加到主畫面與通知](/help/add-to-home-screen)。
