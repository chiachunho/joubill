# 匯出

想把群組的帳拿到別的地方用，有兩種格式：

| 格式          | 適合                              | 內容                           | 會傳到群組嗎               |
| ------------- | --------------------------------- | ------------------------------ | -------------------------- |
| **CSV**       | 用 Excel、Google 試算表對帳或留存 | 整個群組的每一筆紀錄           | 會（也可以下載或傳給自己） |
| **Beancount** | 貼進你自己的 beancount 複式帳本   | 只有和你有關的紀錄，以你的角度 | 不會，只給你自己           |

兩種都在 Mini App 或網頁版的「**群組設定 → 匯出**」。

---

## CSV：給試算表

想把整個群組的帳丟進試算表對帳，或旅程結束後留存？下面幾種方式拿到的是同一份檔案：

- 在群組輸入 `/export`，機器人會把 CSV 傳到群組裡。在跟機器人的私訊裡打 `/export`，CSV 會傳給你自己，不會出現在群組。
- 在「群組設定 → 匯出」按「**匯出 CSV 到群組**」（Mini App 和網頁版都有），效果和 `/export` 一樣。網頁版另外有「**下載 CSV**」，直接存到你的電腦。
- 還沒綁定 Telegram 群組的群組沒有聊天室可以傳，匯出頁會改成說明，並提供「綁定 Telegram 群組」；在 Mini App 裡還有「用瀏覽器開啟網頁版下載」。

每一列是一筆紀錄，支出和還款都在裡面（「類型」欄區分）。欄位：日期、類型、說明、金額、幣別、換算金額、換算幣別、匯率、付款人、分攤、記錄者、建立時間。付款人和分攤有多人時寫成 `A:300; B:200`。

- 用 Excel 或 Google 試算表開都不會亂碼。
- 「日期」是消費日期（只有日期，沒有時間，記帳時選哪天就是哪天）；「建立時間」是這筆被記下的時間，一律用 **UTC**（不是群組時區）。
- 「換算金額」是換成群組預設貨幣的金額，用的匯率和餘額計算完全相同（見[多幣別](/help/multi-currency#跨幣別的餘額怎麼計算)），並保留 4 位小數，這樣整欄加總才會和 `/balance` 對得起來；要看整數請在試算表裡設定顯示格式。
- 傳到群組的檔案**所有成員都看得到**，和 `/balance` 一樣；私訊的 `/export` 和網頁版下載只有你拿到。

---

## Beancount：給你自己的帳本

[beancount](https://github.com/beancount/beancount) 是一套純文字的複式記帳格式。揪帳可以把這個群組裡**和你有關的紀錄**匯出成一份 `.beancount` 檔，貼進你自己的帳本。這是你個人的帳本，不會傳到群組。

在「**群組設定 → 匯出**」的 Beancount 區塊：

1. 選範圍：
   - **上次匯出後的變動**：從上次匯出之後才記的支出和還款，加上已經匯出過、之後被修改或刪除的紀錄（見下方的修正分錄），適合每隔一段時間匯一次。第一次匯出之前不會出現這個選項。頁面會分開顯示「新增 N 筆，修正 M 筆」。
   - **全部**：這個群組的每一筆。
   - **自訂日期範圍**：依消費日期挑一段。這個選項不會更新「上次匯出」的位置。
2. 網頁版按「**下載 .beancount**」存到電腦；Mini App 和網頁版都可以按「**傳到我的私訊**」，機器人會把檔案私訊給你。第一次用私訊之前，要先打開和機器人的私訊、按一次「開始」，否則機器人沒辦法傳訊息給你。

每一筆都是**以你的角度**記的：

| 帳戶                                           | 記什麼                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| Expenses 帳戶（預設 `Expenses:Uncategorized`） | 你自己分攤的部分                                                   |
| Cash 帳戶（預設 `Assets:Cash`）                | 你實際付出或收到的錢                                               |
| 活動帳戶（預設 `Assets:Receivable:群組名稱`）  | 你和群組其他人之間的差額，不分是誰；它的餘額就是你在這個群組的結餘 |

跟你無關的紀錄（別人之間的還款、你沒參與的支出）不會出現在檔案裡。跨幣別時每一筆分錄都會附上 `@ 匯率`，用的匯率和餘額計算相同，所以在原幣和群組預設貨幣下都會平衡。

三個帳戶都可以在「**群組設定 → 匯出**」的「Beancount 帳戶設定」改成你自己帳本慣用的名稱，只影響你自己的匯出。

- 每一筆都帶 `joubill_id`，是揪帳裡這筆紀錄的編號。
- 已經匯出的紀錄之後被**修改或刪除**時，「上次匯出後的變動」會輸出**修正分錄**，帶有 `joubill_correction: "edited"` 或 `"deleted"`。刪除會輸出一筆沖銷，把當初匯出的分錄全部反向；修改會輸出兩筆，先沖銷當初匯出的版本，再寫入現在的版本。沖銷加上原本那一筆，淨額為零。改完之後變得和你無關的紀錄只有沖銷；原本無關、改完變得和你有關的，當作新紀錄。只改說明、收據這類不影響你帳本的修改不會產生修正。
- 修正不包含匯率的事後變動（鎖定匯率或改群組匯率），也不包含認領成員或合併帳號造成的變動；這些請用 `joubill_id` 對照自己調整。
- 更新揪帳之前就匯出過的人，第一次「上次匯出後的變動」不會有修正分錄（揪帳還不知道那一次的檔案包含哪些修改），之後才會開始。
- 檔案開頭會有活動帳戶的 `open`；Expenses 和 Cash 你的帳本多半已經開過，所以是註解，需要的話把行首的 `;` 拿掉。只匯出新紀錄或自訂範圍時，活動帳戶的 `open` 也是註解，避免重複開帳。
- 揪帳本身沒有記帳科目的概念，所以 Expenses 帳戶固定是一個分類，需要你貼進帳本後自己再改成正確的科目。
