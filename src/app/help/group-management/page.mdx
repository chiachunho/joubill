# 群組與成員

## 誰會自動加入帳本？

會自動登記的只有這幾種：

1. **用過機器人的人**：打過指令、`@` 過機器人，或回覆過機器人訊息
2. **被加進 Telegram 群組**：機器人在場時有人被拉進來
3. **`/add` 裡用提及選單點到的人**（限沒有設定 username 的帳號）

> **在群組聊天不會被登記。** Telegram 機器人預設是「隱私模式」，只看得到指令、`@` 它的訊息和對它的回覆，一般聊天內容根本收不到。
>
> 另外，**建立群組時把機器人一起拉進去，只會登記建立者**——Telegram 的機器人介面不會傳出當下的成員名單。

所以多數情況下，你會需要用下面的 `/join` 手動補人。

---

## 用 `/join` 把人加進帳本

**回覆對方的任何一則訊息，然後打 `/join`。**

```
（回覆 Alice 的訊息）
/join
```

機器人會確認 Alice 確實在這個 Telegram 群組裡，然後把她加進帳本，並回覆「✅ 已加入 1 人：Alice」。

一次回覆一個人。群組裡任何成員都可以這樣做，不限管理員。

### 為什麼不能直接打 `@名字`？

因為 Telegram **沒有提供「用 username 查使用者」的介面**。機器人唯一能做的是拿你打的字去比對它看過的舊資料，而 username 是可以改、可以轉手的——比對到一個換過主人的舊名字，就會默默把錯的人加進帳本，而且系統無從察覺。

所以 `/join` 遇到打字打出來的 `@名字` 時會**什麼都不做**，直接請你改用回覆的方式。這是刻意的取捨：寧可多按一下，也不要把陌生人算進大家的帳裡。

> 另一個相關的限制：從 `@` 選單點人時，Telegram 會把「有 username 的帳號」自動改寫成純文字的 `@名字`，只有**沒有 username** 的帳號才會保留完整身分。所以提及選單只對少數人有效，回覆才是可靠的做法。

### 如果加不進去

| 機器人的回應              | 意思                                               |
| ------------------------- | -------------------------------------------------- |
| ⚠️ 不在這個 Telegram 群組 | 對方確實不在這個群組裡，先請他加入                 |
| ⚠️ 無法確認是否在群組裡   | 機器人問不到對方的狀態，通常是暫時性問題，稍後再試 |

還有一個備用方式：在**和機器人的私人對話**裡，把對方的任意訊息**轉傳**給機器人，它會列出你的群組讓你選。如果對方開了「隱藏轉傳來源」，這條路就走不通。

## 把網頁建立的群組綁到聊天室

在網頁版建立的群組一開始沒有 Telegram 聊天室。在要綁定的 Telegram 群組輸入 `/link 邀請碼` 就能綁定，綁錯了或想換一個，也可以解除綁定（群組設定 → Telegram 群組，或在聊天室輸入 `/unlink`），詳見[網頁建群組與邀請碼](/help/invite-members)。

## 管理成員

在 Mini App 或網頁版進入群組 → 點右上角**齒輪圖示**進入「**群組設定**」→「**成員**」區塊。

每位成員右邊有兩個控制項：

- **狀態按鈕**（顯示「啟用中」或「停用中」）：點一下切換
- **垃圾桶圖示**：把成員從帳本移除

停用中的成員頭像會變淡，名字下面標示「已停用」，並排在清單最後面。

---

## 新增沒有帳號的成員

有人不用 Telegram、也不想登入？在「成員」清單最下方點「**＋ 新增成員**」，選「**新增沒有帳號的成員**」，輸入名字就好。（同一個按鈕選「**用邀請碼邀請**」，可以把連結或邀請碼傳給有帳號的人，見[網頁建群組與邀請碼](/help/invite-members)。）

- 群組裡只有你一個人時，群組主頁的「還沒有其他成員」卡片也有「**新增成員**」按鈕，不用先進群組設定。
- 他可以當付款人，也可以被分攤；機器人的 ⚙️ 調整 →「👥 誰分」會自動列出他。
- `/balance`、`/settle` 和費用卡片會用純文字顯示他的名字（沒有 @ 提及）。
- 清單裡他的名字旁會標示「**無帳號**」，右邊多一個**鉛筆圖示**可以改名。
- 名字在同一個群組裡不能重複。
- 規則和其他成員一樣：有費用記錄就只能停用，沒有才能刪除。

### 他本人加入之後：合併到真人帳號

沒有帳號的成員之後自己加入了，可以把他的紀錄併到他的帳號：點他那一列的**合併圖示**（分岔箭頭），選一位真實成員。確認視窗會寫出會帶走幾筆紀錄、多少餘額。

- 合併後，他名下的所有付款和分攤都改記在對方名下，`/balance` 的總和不變，「無帳號」的名字會從成員清單消失。
- **合併後無法還原**，也不需要其他成員同意。選之前請確認是同一個人。
- 同一筆費用裡兩個人都有分攤時，會合成一筆；如果原本是「份數」，份數會相加。「調整」類型的分帳會改成各自的固定金額。
- 如果你和他之間記過還款，合併後那幾筆會變成「自己還自己」。確認視窗會問你要**保留**（預設，之後不能編輯，只能刪除）還是**一併刪除**（不影響餘額，動態紀錄和群組訊息會留下刪除記錄）。
- 動態紀錄會留下「X 認領了 Y」，被改的那幾筆費用的歷史裡也看得到。
- Telegram 群組的真人是機器人自動加入的，所以用這個入口；用邀請連結加入的人，可以在加入時直接認領（見[網頁建群組與邀請碼](/help/invite-members)）。

## 啟用 vs. 停用

| 狀態               | 效果                                                   |
| ------------------ | ------------------------------------------------------ |
| **啟用中**（預設） | 新增費用時，預設會被勾選為分帳的參與者                 |
| **停用中**         | 新增費用時**仍然會出現在參與者清單中**，只是預設不勾選 |

停用**不會**影響任何已存在的帳目——過去的費用、餘額、還款記錄全部照舊。它單純是「新費用要不要預設算他一份」的開關。

**什麼時候該停用？**

- 有人中途退出這趟旅程，但之前的帳還要保留
- 某個人大部分新費用都不參與，停用後省得每次手動取消勾選

## 刪除成員的限制

- **可以刪除**：該成員在這個群組裡**沒有任何費用記錄**（既不是任何一筆的付款人，也不是分擔者）
- **只能停用**：只要有任何費用牽涉到他，就無法刪除——系統會提示「無法刪除：此成員有 N 筆費用記錄，只能停用。」

另外，你**不能刪除自己**。

> 這個限制是為了保護帳目完整性。如果把有費用記錄的人刪掉，那些費用就會少掉一個分擔者，餘額會整個算錯。

## 匯出帳目（CSV）

想把整個群組的帳丟進試算表對帳，或旅程結束後留存？有兩種方式，拿到的是同一份檔案：

- 在群組輸入 `/export`，機器人會把 CSV 傳到群組裡。
- 在「群組設定 → 匯出」按「**匯出 CSV 到群組**」（Mini App 和 Web App 都有），效果和 `/export` 一樣。Web App 另外有「**下載 CSV**」，直接存到你的電腦。

每一列是一筆紀錄，支出和還款都在裡面（「類型」欄區分）。欄位：日期、類型、說明、金額、幣別、換算金額、換算幣別、匯率、付款人、分攤、記錄者、建立時間。付款人和分攤有多人時寫成 `A:300; B:200`。

- 用 Excel 或 Google 試算表開都不會亂碼。
- 日期與時間是 **UTC**，台灣時間請加 8 小時。
- 「換算金額」是換成群組預設幣別的金額，用的匯率和餘額計算完全相同（單筆指定匯率 > 群組自訂匯率 > 當天市場匯率），並保留 4 位小數，這樣整欄加總才會和 `/balance` 對得起來；要看整數請在試算表裡設定顯示格式。
- 檔案會出現在群組聊天室，**所有成員都看得到**，和 `/balance` 一樣。

## 匯出成 beancount

[beancount](https://github.com/beancount/beancount) 是一套純文字的複式記帳格式。揪帳可以把這個群組裡**和你有關的紀錄**匯出成一份 `.beancount` 檔，貼進你自己的帳本。這是你個人的帳本，不會傳到群組。

在「**群組設定 → Beancount → 匯出 beancount**」：

1. 選範圍：
   - **上次匯出後的變動**：從上次匯出之後才記的支出和還款，加上已經匯出過、之後被修改或刪除的紀錄（見下方的修正分錄），適合每隔一段時間匯一次。第一次匯出之前不會出現這個選項。頁面會分開顯示「新增 N 筆，修正 M 筆」。
   - **全部**：這個群組的每一筆。
   - **自訂日期範圍**：依消費日期挑一段。這個選項不會更新「上次匯出」的位置。
2. 網頁版按「**下載 .beancount**」存到電腦；Mini App 和網頁版都可以按「**傳到我的私訊**」，機器人會把檔案私訊給你。第一次用私訊之前，要先打開和機器人的私訊、按一次「開始」，否則機器人沒辦法傳訊息給你。

每一筆都是**以你的角度**記的：

| 帳戶                                           | 記什麼                                                             |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| Expenses 帳戶（預設 `Expenses:Uncategorized`） | 你自己分攤的部分                                                   |
| Cash 帳戶（預設 `Assets:Cash`）                | 你實際付出或收到的錢                                               |
| 活動帳戶（預設 `Assets:Receivable:群組名稱`）  | 你和群組其他人之間的差額，不分是誰；它的餘額就是你在這個群組的結餘 |

跟你無關的紀錄（別人之間的還款、你沒參與的支出）不會出現在檔案裡。跨幣別時每一筆分錄都會附上 `@ 匯率`，用的匯率和餘額計算相同，所以在原幣和群組預設貨幣下都會平衡。

三個帳戶都可以在「**群組設定 → Beancount → 帳戶設定**」改成你自己帳本慣用的名稱，只影響你自己的匯出。

- 每一筆都帶 `splitbill_id`，是揪帳裡這筆紀錄的編號。
- 已經匯出的紀錄之後被**修改或刪除**時，「上次匯出後的變動」會輸出**修正分錄**，帶有 `splitbill_correction: "edited"` 或 `"deleted"`。刪除會輸出一筆沖銷，把當初匯出的分錄全部反向；修改會輸出兩筆，先沖銷當初匯出的版本，再寫入現在的版本。沖銷加上原本那一筆，淨額為零。改完之後變得和你無關的紀錄只有沖銷；原本無關、改完變得和你有關的，當作新紀錄。只改說明、收據這類不影響你帳本的修改不會產生修正。
- 修正不包含匯率的事後變動（鎖定匯率或改群組匯率），也不包含認領成員或合併帳號造成的變動；這些請用 `splitbill_id` 對照自己調整。
- 更新揪帳之前就匯出過的人，第一次「上次匯出後的變動」不會有修正分錄（揪帳還不知道那一次的檔案包含哪些修改），之後才會開始。
- 檔案開頭會有活動帳戶的 `open`；Expenses 和 Cash 你的帳本多半已經開過，所以是註解，需要的話把行首的 `;` 拿掉。只匯出新紀錄或自訂範圍時，活動帳戶的 `open` 也是註解，避免重複開帳。
- 揪帳本身沒有記帳科目的概念，所以 Expenses 帳戶固定是一個分類，需要你貼進帳本後自己再改成正確的科目。

## 刪除整個群組

在「群組設定」最下方有「**危險區域**」（預設收合，點一下標題展開），裡面是「**刪除群組**」。刪除後所有費用與還款記錄都會**永久清除**，而且機器人會自動離開這個 Telegram 群組（[網頁建立的群組](/help/invite-members)沒有聊天室，所以沒有這一步）。

流程依群組人數而不同：

**帳本只有你一個人** — 確認後立即刪除。

**帳本有多位成員** — 需要另一位成員同意，避免一個人就把大家的帳全部刪掉：

1. 你按下「刪除群組」，送出一則**刪除申請**
2. 機器人會在 Telegram 群組發訊息公告，附上「**✓ 同意刪除**」和「**✗ 拒絕**」兩個按鈕
3. 其他成員可以在 Telegram 訊息上直接按，或在群組主頁頂端的提示（也可以在「群組設定 → 危險區域」）裡按「同意刪除」／「拒絕」
4. 只要**任何一位其他成員同意**，群組就會立刻刪除，機器人也會離開群組

申請送出後，你自己會在危險區域看到「等待其他成員確認」，隨時可以按「**取消申請**」撤回。其他成員也可以按「拒絕」把申請擋下來。

> 幾個要注意的地方：申請者**不能同意自己的申請**；申請 **48 小時**後會自動失效，過期後需要重新申請；刪除之後資料無法復原。

## 群組名稱和頭像

直接同步自 Telegram，不需要另外設定。（網頁建立的群組沒有 Telegram 聊天室，名稱在建立時決定，頭像用名稱的首字。）群組改名或換頭像後，下次有人和機器人互動時就會自動更新。

如果群組從一般群組被升級成**超級群組**（supergroup），Telegram 會換一組新的群組編號。機器人會自動跟著換過去，原本的成員和帳目都會保留，不需要重新設定。

## 常見問題

**成員已經離開 Telegram 群組，他的帳怎麼辦？**

帳目不受 Telegram 群組成員變動影響，他的餘額仍然存在。建議把他改成「停用」，讓他不再出現在新費用裡，然後照常記錄還款把帳結清。

**同一個人在兩個群組都有帳，會混在一起嗎？**

不會。每個群組是完全獨立的帳本，餘額、費用、還款記錄都分開計算。

**可以把某個群組的費用搬到另一個群組嗎？**

目前不行，費用會固定屬於建立時的群組。
