# 群組與成員

## 誰會自動加入帳本？

帳本裡的成員是慢慢累積出來的。會自動登記的有這幾種：

1. **自己點「開啟揪帳」**：在群組裡點機器人訊息上的「**開啟揪帳**」按鈕打開 Mini App，機器人確認你在這個 Telegram 群組裡，就會把你加進帳本。**請朋友點一下這顆按鈕，是讓大家加進來最快的方法。**
2. **用過機器人的人**：打過指令、`@` 過機器人，或回覆過機器人訊息
3. **被加進 Telegram 群組**：機器人在場時有人被拉進來
4. **用邀請連結加入 Telegram 群組的人**：只有機器人是這個群組的**管理員**時才收得到這個通知（見下方提示）
5. **`/add` 裡用提及選單點到的人**（限沒有設定 username 的帳號）

> **在群組聊天不會被登記。** Telegram 機器人預設是「隱私模式」，只看得到指令、`@` 它的訊息和對它的回覆，一般聊天內容根本收不到。而且 Telegram 沒有「列出群組所有成員」的介面，機器人無法一次把大家抓進來。
>
> 另外，**建立群組時把機器人一起拉進去，只會登記建立者**——Telegram 的機器人介面不會傳出當下的成員名單。

> **把機器人設成群組管理員**，它就能收到每個人加入群組的通知（包括用邀請連結加入的），也能更準確地確認某人是否在群組裡。不需要給它任何特別的權限，預設的管理員權限就夠了。

上面都沒抓到的人，用下面的 `/join` 手動補上。

## 用 `/join` 把人加進帳本

**回覆對方的任何一則訊息，然後打 `/join`。**

```
（回覆 Alice 的訊息）
/join
```

機器人會確認 Alice 確實在這個 Telegram 群組裡，然後把她加進帳本，並回覆「✅ Alice 加入了」。

只打 `/join` 沒回覆任何人時，機器人會說明用法，並附上「**開啟揪帳**」按鈕：想把**自己**加進來，點它就好。

一次回覆一個人。群組裡任何成員都可以這樣做，不限管理員。

### 為什麼不能直接打 `@名字`？

因為 Telegram **沒有提供「用 username 查使用者」的介面**。機器人唯一能做的是拿你打的字去比對它看過的舊資料，而 username 是可以改、可以轉手的——比對到一個換過主人的舊名字，就會默默把錯的人加進帳本，而且系統無從察覺。

所以 `/join` 遇到打字打出來的 `@名字` 時會**什麼都不做**，直接請你改用回覆的方式。這是刻意的取捨：寧可多按一下，也不要把陌生人算進大家的帳裡。

> 另一個相關的限制：從 `@` 選單點人時，Telegram 會把「有 username 的帳號」自動改寫成純文字的 `@名字`，只有**沒有 username** 的帳號才會保留完整身分。所以提及選單只對少數人有效，回覆才是可靠的做法。

### 如果加不進去

| 機器人的回應                | 意思                                               |
| --------------------------- | -------------------------------------------------- |
| • Bob 已經在了              | 他本來就在帳本裡，不用再加                         |
| ⚠️ Bob 不在這個群組         | 對方確實不在這個群組裡，先請他加入                 |
| ⚠️ Bob 確認不到，請再試一次 | 機器人問不到對方的狀態，通常是暫時性問題，稍後再試 |
| ⚠️ @bob 要用回覆的方式加    | 你打的是 `@名字`，改成回覆他的訊息再打 `/join`     |

還有一個備用方式：在**和機器人的私人對話**裡，把對方的任意訊息**轉傳**給機器人，它會列出你的群組讓你選。如果對方開了「隱藏轉傳來源」，這條路就走不通。

## 把網頁建立的群組綁到聊天室

在網頁版建立的群組一開始沒有 Telegram 聊天室。在要綁定的 Telegram 群組輸入 `/link 邀請碼` 就能綁定，綁錯了或想換一個，也可以解除綁定（群組設定 → Telegram 群組 → 解除綁定，或在聊天室輸入 `/unlink`），詳見[邀請成員與網頁群組](/help/invite-members)。

## 管理成員

在 Mini App 或網頁版進入群組 → 點右上角**齒輪圖示**進入「**群組設定**」，成員就列在頁面最上面，分成兩組：

- **一起分帳**：新增支出時預設會勾選他們
- **暫停分帳**：新增支出時仍會出現在參與者清單裡，只是預設不勾選；頭像會變淡。按旁邊的「**恢復**」就回到「一起分帳」

其他動作在每一列右邊的「**⋯**」選單裡：「暫停分帳」、「移出群組」，沒有帳號的成員另外有「改名」和「合併到真人成員…」。你自己的選單沒有「移出群組」。

## 新增沒有帳號的成員

有人不用 Telegram、也不想登入？在成員清單最下方點「**＋ 新增成員**」，選「**新增沒有帳號的成員**」，輸入名字就好。（同一個按鈕選「**用邀請碼邀請**」，可以把連結或邀請碼傳給有帳號的人，見[邀請成員與網頁群組](/help/invite-members)。）

- 群組裡只有你一個人時，群組主頁的「還沒有其他成員」卡片也有「**新增成員**」按鈕，不用先進群組設定。
- 他可以當付款人，也可以被分攤；機器人的 ☰ 調整 →「誰分」會自動列出他。
- `/balance`、`/settle` 和支出卡片會用純文字顯示他的名字（沒有 @ 提及）。
- 清單裡他的名字旁會標示「**無帳號**」，他的「**⋯**」選單裡多了「**改名**」。
- 名字在同一個群組裡不能重複。
- 規則和其他成員一樣：有紀錄就只能暫停分帳，沒有才能移出。

### 他本人加入之後：合併到真人帳號

沒有帳號的成員之後自己加入了，可以把他的紀錄併到他的帳號：點他那一列的「**⋯**」→「**合併到真人成員…**」，選一位真實成員。確認視窗會寫出會帶走幾筆紀錄、多少餘額。

- 合併後，他名下的所有付款和分攤都改記在對方名下，`/balance` 的總和不變，「無帳號」的名字會從成員清單消失。
- **合併後無法還原**，也不需要其他成員同意。選之前請確認是同一個人。
- 同一筆支出裡兩個人都有分攤時，會合成一筆；如果原本是「份數」，份數會相加。「調整」類型的分帳會改成各自的固定金額。
- 如果你和他之間記過還款，合併後那幾筆會變成「自己還自己」。確認視窗會問你要**保留**（預設，之後不能編輯，只能刪除）還是**一併刪除**（不影響餘額，動態紀錄和群組訊息會留下刪除紀錄）。
- 動態紀錄會留下「X 認領了 Y」，被改的那幾筆支出的歷史裡也看得到。
- Telegram 群組的真人是機器人自動加入的，所以用這個入口；用邀請連結加入的人，可以在加入時直接認領（見[邀請成員與網頁群組](/help/invite-members)）。

## 一起分帳 vs. 暫停分帳

| 分組                 | 效果                                                   |
| -------------------- | ------------------------------------------------------ |
| **一起分帳**（預設） | 新增支出時，預設會被勾選為分帳的參與者                 |
| **暫停分帳**         | 新增支出時**仍然會出現在參與者清單中**，只是預設不勾選 |

暫停**不會**影響任何已存在的帳目——過去的支出、餘額、還款紀錄全部照舊。它單純決定「新支出要不要預設算他一份」。

**什麼時候該暫停？**

- 有人中途退出這趟旅程，但之前的帳還要保留
- 某個人大部分新支出都不參與，暫停後省得每次手動取消勾選

## 移出成員的限制

- **可以移出**：該成員在這個群組裡**沒有任何紀錄**（既不是任何一筆的付款人，也不是分攤的人）
- **只能暫停分帳**：只要有任何紀錄牽涉到他，就無法移出——確認視窗會寫「還有 N 筆紀錄，不能移出」，並直接提供「**改為暫停分帳**」。

另外，你**不能移出自己**。

> 這個限制是為了保護帳目完整性。如果把有紀錄的人移出，那些支出就會少掉一個分攤的人，餘額會整個算錯。

## 群組時區

每個群組有一個「時區」，預設是 Asia/Taipei（台北，UTC+8）。它只做兩件事：

1. 決定機器人的 `/add` 在你沒有指定日期時，把支出記在**哪一天**——也就是這個時區的「今天」。
2. 決定查匯率時「今天」是哪一天。

它**不會**改變已經記好的紀錄：每一筆紀錄的日期就是你記帳時選的那一天，之後改時區也不會動。

任何成員都可以改，三個地方都行：

- **建立群組時**：時區預設為你裝置目前的時區，可以直接改。
- **群組設定 → 貨幣與匯率 → 時區**（Mini App 和網頁版都有）：選好之後會先確認，因為這會影響整個群組。
- **在群組輸入 `/timezone`**：機器人列出常用的時區（例如 `Asia/Taipei (UTC+8)`、`Asia/Tokyo (UTC+9)`），點一下就改好；其他時區請到群組設定選。

出國旅行時，如果你的裝置時區和群組的時區 UTC 偏移不同，進入群組頁會問你要不要改成裝置的時區。選「不用」之後，這台裝置不會再問，除非你的裝置時區又換了。偏移相同的時區（例如台北和新加坡）不會問。

每次修改都會記在群組的「動態紀錄」裡。

## 記帳通知發送位置（主題）

Telegram 群組開啟「主題」（Topics）功能後，可以指定一個主題，讓記帳通知集中在那裡，不會洗掉其他聊天。

會發到指定主題的是**沒有對話可回**的訊息：

- 在 Mini App、網頁版或連結的應用程式新增的記帳卡片和還款通知
- 從 App 傳到群組的 CSV 匯出檔、刪除群組的公告

在群組裡打的指令（`/add`、`/balance`…）**回覆會留在打指令的地方**，在哪個主題打就回在哪個主題。修改和刪除也一樣：卡片會在原本的位置更新。

### 怎麼設定

Telegram 機器人沒辦法列出群組有哪些主題，所以要在 Telegram 裡選：

1. 到想要的主題裡輸入 `/topic`
2. 按機器人回覆裡的「**改發到「主題名稱」**」

要改回 General，在 `/topic` 的回覆裡按「**↺ 改回 General**」，或到**群組設定 → Telegram 群組 → 記帳通知發送位置**按「改回 General」。群組沒有開啟主題功能時，這個設定不會出現。

任何成員都可以改，每次修改都會記在「動態紀錄」裡。如果指定的主題被刪除或關閉，機器人會在 General 說一聲，之後的通知改發在 General。

## 刪除整個群組

在「群組設定」最下面有一列紅字的「**刪除群組**」。刪除後所有支出與還款紀錄都會**永久清除**，而且機器人會自動離開這個 Telegram 群組（[網頁建立的群組](/help/invite-members)沒有聊天室，所以沒有這一步）。

流程依群組人數而不同：

**帳本只有你一個人** — 確認後立即刪除。

**帳本有多位成員** — 需要另一位成員同意，避免一個人就把大家的帳全部刪掉：

1. 你按下「刪除群組」，送出一則**刪除申請**
2. 機器人會在 Telegram 群組發訊息公告，附上「**✓ 同意刪除**」和「**✗ 拒絕**」兩個按鈕
3. 其他成員可以在 Telegram 訊息上直接按，或在群組主頁頂端的提示（也可以在「群組設定」最下面那一列）裡按「同意刪除」／「拒絕」
4. 只要**任何一位其他成員同意**，群組就會立刻刪除，機器人也會離開群組

申請送出後，你自己會在「群組設定」最下面那一列看到「等待其他成員確認」，隨時可以按「**取消申請**」撤回。其他成員也可以按「拒絕」把申請擋下來。

> 幾個要注意的地方：申請者**不能同意自己的申請**；申請 **48 小時**後會自動失效，過期後需要重新申請；刪除之後資料無法復原。

## 群組名稱和頭像

直接同步自 Telegram，不需要另外設定。（網頁建立的群組沒有 Telegram 聊天室，名稱在建立時決定，頭像用名稱的首字。）群組改名或換頭像後，下次有人和機器人互動時就會自動更新。

如果群組從一般群組被升級成**超級群組**（supergroup），Telegram 會換一組新的群組編號。機器人會自動跟著換過去，原本的成員和帳目都會保留，不需要重新設定。

## 常見問題

**成員已經離開 Telegram 群組，他的帳怎麼辦？**

帳目不受 Telegram 群組成員變動影響，他的餘額仍然存在。建議把他改成「暫停分帳」，新支出就不會預設算他一份，然後照常記錄還款把帳結清。

**同一個人在兩個群組都有帳，會混在一起嗎？**

不會。每個群組是完全獨立的帳本，餘額、支出、還款紀錄都分開計算。

**可以把某個群組的支出搬到另一個群組嗎？**

目前不行，支出會固定屬於建立時的群組。
