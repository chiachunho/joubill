# 用 MCP 串接 Claude、ChatGPT 與自動化

## 這是什麼？

揪帳提供一個 **MCP 伺服器**，讓 Claude、Cursor、n8n 等工具可以在你授權的範圍內，幫你查餘額、看紀錄，也可以記帳。例如：

- 在 Claude 上說「這張收據記到東京旅行，我付的，跟阿華、Jenny 均分」。
- 讓 n8n 或捷徑把信用卡刷卡通知自動記到「室友」群組。
- 問「我在東京旅行欠誰多少？」。

在揪帳裡，每個這樣的連線叫一個**連結的應用程式**，管理的地方在 **個人設定 → 連結的應用程式**。

---

## 建立個人存取權杖

1. 在網頁版或 Mini App 開啟 **個人設定 → 連結的應用程式**。
2. 按 **建立個人存取權杖**，填寫：
   - **名稱**：之後在清單和群組紀錄裡會看到，例如「我的 n8n」。
   - **權限**：預設是**唯讀**（只能查）；選**可記帳**才能新增紀錄。
   - **可以存取的群組**：預設一個都不勾，請自己勾選。「所有群組，含之後加入的」會連你之後加入的群組一起開放，不建議隨便勾。
   - **到期**：30 天、90 天或不過期。
3. 按 **建立**，畫面會顯示權杖（以 `sbk_` 開頭）。**只會顯示這一次**，請馬上複製。弄丟的話，撤銷後再建一組。

> 權杖等同你的密碼的一部分：拿到的人可以在你勾選的群組內做權限允許的事。請只貼到你信任的工具裡。

---

## 設定範例

先在 **連結的應用程式** 頁複製 **MCP 伺服器網址**，下面的 `<MCP 伺服器網址>` 請換成它，`sbk_…` 換成你的權杖。

**Claude Code**

```bash
claude mcp add --transport http splitbill <MCP 伺服器網址> \
  --header "Authorization: Bearer sbk_…"
```

**Cursor**（`.cursor/mcp.json`）

```json
{
  "mcpServers": {
    "splitbill": {
      "url": "<MCP 伺服器網址>",
      "headers": { "Authorization": "Bearer sbk_…" }
    }
  }
}
```

**n8n、捷徑或自己的腳本**：對 MCP 伺服器網址送 HTTP 請求，加上 `Authorization: Bearer sbk_…` 標頭。

---

## 它可以做什麼

| 權限   | 可以做的事                                     |
| ------ | ---------------------------------------------- |
| 唯讀   | 列出群組、查成員、看餘額與建議結清方式、查紀錄 |
| 可記帳 | 再加上新增費用與還款                           |

人名只會在**同一個群組的現有成員**裡比對；對不到或有好幾個符合時，它會回報候選名單，不會亂猜。重複送出同一筆時，帶相同的 `idempotencyKey` 就不會記兩次；相同金額、幣別、付款人在 10 分鐘內再記，會先提醒。

**不能做的事**：建立或刪除群組、邀請成員、合併帳號、修改匯率設定。這些只能在 App 裡操作。

---

## 群組裡看得到嗎？

看得到，而且不能關掉。透過應用程式記下的每一筆：

- 群組卡片多一行「✦ 小明 透過 Claude 記錄」。
- 編輯畫面寫著「由 小明 透過 Claude 於 … 記錄」。
- 動態紀錄的頭像有角標，可以用 **透過應用程式** 篩出來。
- 推播通知也會標明是透過哪個應用程式。

群組裡的其他成員一樣可以修改或刪除這些紀錄。

---

## 修改範圍或撤銷

在 **連結的應用程式** 點進某一個，可以改權限和群組範圍，或**撤銷**。撤銷後它立刻無法再讀取或記帳；它之前記下的紀錄會保留，並仍標示是透過它記錄的。

你離開某個群組後，所有連結的應用程式也會立刻看不到那個群組。

每個連結的應用程式有速率限制（每小時 600 次讀取、60 次寫入），超過時會暫時被拒絕。
