# 用 MCP 串接 Claude、ChatGPT 與自動化

## 這是什麼？

揪帳提供一個 **MCP 伺服器**，讓 Claude、Cursor、n8n 等工具可以在你授權的範圍內，幫你查餘額、看紀錄，也可以記帳。例如：

- 在 Claude 上說「這張收據記到東京旅行，我付的，跟阿華、Jenny 均分」。
- 讓 n8n 或捷徑把信用卡刷卡通知自動記到「室友」群組。
- 問「我在東京旅行欠誰多少？」。

在揪帳裡，每個這樣的連線叫一個**連結的應用程式**，管理的地方在 **個人設定 → 連結的應用程式**。

---

## 連結 Claude.ai 或 ChatGPT

這兩個服務不能自己填標頭，所以用「新增連接器」登入，不需要權杖。

1. 在網頁版開啟 **個人設定 → 連結的應用程式**，複製 **MCP 伺服器網址**。
2. 在 Claude.ai（設定 → 連接器 → 新增自訂連接器）或 ChatGPT（設定 → 連接器 → 新增）貼上網址。
3. 它會開啟揪帳網頁版的授權頁。沒登入的話先登入，再選要開放的**群組**和**權限**（唯讀或可記帳），按 **允許**。
4. 回到 Claude 或 ChatGPT，連接器就會顯示已連線。

授權頁會寫出是哪個應用程式、授權會交給哪個網址；如果網址你不認得，請按取消。

授權頁**只在網頁版**，Mini App 不支援（Telegram 內建的瀏覽器無法完成 OAuth）。在 Mini App 開到時，會提示你改用瀏覽器開啟。

連結後它會出現在 **連結的應用程式** 清單，可以改權限和群組範圍，或隨時撤銷，做法和個人存取權杖一樣。授權每次最長 1 小時，應用程式會自動換新；撤銷後立刻失效。

---

## 用個人存取權杖連結 Claude Code、Cursor、n8n 等

1. 在網頁版或 Mini App 開啟 **個人設定 → 連結的應用程式**。
2. 按 **建立個人存取權杖**，填寫：
   - **名稱**：之後在清單和群組紀錄裡會看到，例如「我的 n8n」。
   - **權限**：預設是**唯讀**（只能查）；選**可記帳**才能新增紀錄。
   - **可以存取的群組**：預設一個都不勾，請自己勾選。「所有群組，含之後加入的」會連你之後加入的群組一起開放，不建議隨便勾。
   - **到期**：30 天、90 天或不過期。
3. 按 **建立**，畫面會顯示權杖（以 `sbk_` 開頭）。**只會顯示這一次**，請馬上複製。弄丟的話，撤銷後再建一組。

> 權杖等同你的密碼的一部分：拿到的人可以在你勾選的群組內做權限允許的事。請只貼到你信任的工具裡。

## 設定範例

先在 **連結的應用程式** 頁複製 **MCP 伺服器網址**，下面的 `<MCP 伺服器網址>` 請換成它，`sbk_…` 換成你的權杖。

**Claude Code**

```bash
claude mcp add --transport http joubill <MCP 伺服器網址> \
  --header "Authorization: Bearer sbk_…"
```

**Cursor**（`.cursor/mcp.json`）

```json
{
  "mcpServers": {
    "joubill": {
      "url": "<MCP 伺服器網址>",
      "headers": { "Authorization": "Bearer sbk_…" }
    }
  }
}
```

**Claude Code 外掛**：不想自己寫設定的話，安裝外掛就會一次設好。先在 個人設定 建立個人存取權杖，把網址（不含結尾斜線，例如 `https://你的網域`）和權杖放進啟動 Claude Code 的環境變數 `SPLITBILL_URL` 與 `SPLITBILL_TOKEN`，再執行：

```
/plugin marketplace add chiachunho/joubill
/plugin install joubill@joubill
```

外掛包含 MCP 伺服器設定和一個 skill，不需要再手動 `claude mcp add`。

**n8n、捷徑或自己的腳本**：對 MCP 伺服器網址送 HTTP 請求，加上 `Authorization: Bearer sbk_…` 標頭。

## 它可以做什麼

| 權限   | 可以做的事                                         |
| ------ | -------------------------------------------------- |
| 唯讀   | 列出群組、查成員、看餘額與建議結清方式、查紀錄     |
| 可記帳 | 再加上新增支出與還款、修改與刪除紀錄、附上收據照片 |

**寫入前會先給你確認**：新增、修改和刪除都會先預覽（`dryRun`），等你同意才真的寫入。修改時會比對它讀到的版本，期間如果有別人改過，就不會覆蓋，而是回報衝突請你確認。刪除後，群組裡的訊息會變成已刪除的紀錄，並寫明是誰透過哪個應用程式刪的。

人名只會在**同一個群組的現有成員**裡比對；對不到或有好幾個符合時，它會回報候選名單，不會亂猜。重複送出同一筆時，帶相同的 `idempotencyKey` 就不會記兩次；相同金額、幣別、付款人在 10 分鐘內再記，會先提醒。

**收據**：把收據照片給它，它可以在記帳時一併附上，也可以事後補到已經記好的支出上，每筆最多 5 張（jpeg、png、webp，每張 10 MB 以內）。照片存在揪帳的儲存空間，群組裡那則訊息會原地更新，不會多發一則。想把一張收據逐項分給不同的人，可以在 Claude 選 **拆收據** 這個提示：它會一項一項問是誰的，隨時告訴你每個人累計多少、還有多少沒分，最後用指定金額記成一筆，並附上照片。

**不能做的事**：建立或刪除群組、邀請成員、合併帳號、修改匯率設定。這些只能在 App 裡操作。

## 群組裡看得到嗎？

看得到，而且不能關掉。透過應用程式記下的每一筆：

- 群組卡片多一行「✦ 小明 透過 Claude 記錄」。
- 編輯畫面寫著「由 小明 透過 Claude 於 … 記錄」。
- 動態紀錄的頭像有角標，可以用 **透過應用程式** 篩出來。
- 推播通知也會標明是透過哪個應用程式。

群組裡的其他成員一樣可以修改或刪除這些紀錄。

---

## 看它做過什麼

在 個人設定 → 連結的應用程式 點開一個連線，選 **使用紀錄**，可以看到它最近 30 天的每一次呼叫和結果：成功、只是預覽、被拒絕或失敗，以及哪些寫入了紀錄。可以篩選只看寫入或失敗。

使用紀錄只保存工具名稱、群組、結果和對應的紀錄，**不保存你說的話、紀錄的說明文字或收據圖片**。

## 修改範圍或撤銷

在 **連結的應用程式** 點進某一個，可以改權限和群組範圍，或**撤銷**。撤銷後它立刻無法再讀取或記帳；它之前記下的紀錄會保留，並仍標示是透過它記錄的。

你離開某個群組後，所有連結的應用程式也會立刻看不到那個群組。

每個連結的應用程式有速率限制（每小時 600 次讀取、60 次寫入），超過時會暫時被拒絕。
