# 查看帳務

## `/balance`：每個人的淨額

在群組輸入 `/balance`，機器人會列出帳本中每位成員的**淨餘額**，由多到少排序：

```
💰 日本行　餘額 · TWD

🟢 Alice　+1,200
🔴 Bob　−450
🔴 你　−750
```

- **🟢 正數**：你先幫大家墊了錢，別人要還你
- **🔴 負數**：你還欠別人錢

已經完全結清（餘額為零）的人不會出現在清單上。如果整個群組都沒有結餘，機器人會回「這個群組目前沒有結餘，可能還沒記任何支出。」

---

## `/list`：最近的費用

在群組輸入 `/list`，顯示最近 **10 筆**費用，依消費日期由新到舊：

```
最近 10 筆
07/12  @alice  1200 TWD  晚餐
07/11  你      480 TWD   超市採購
```

每一行依序是**消費日期**、**付款人**、**金額與幣別**、**說明**。多人共付時會列出所有付款人。

還沒有任何費用時，機器人會提示「這個群組還沒有任何支出，試試 `/add 50 飲料`」。

---

## `/settle`：還款建議

在群組輸入 `/settle`，機器人會算出**轉帳次數最少**的還款方案：

```
🤝 日本行　還款建議 · TWD

Bob → Alice　450
你 → Alice　750
```

演算法每次都拿「欠最多的人」去還「被欠最多的人」，盡量把多筆零碎欠款合併成一次轉帳。金額以群組的**預設貨幣**顯示。

全部結清時會回「目前沒有未結算的金額 🎉」。

## 圖形介面的群組主頁

在 Mini App 或網頁版開啟群組後，主頁由三個區塊組成：

### Balance（餘額）

標題會帶上群組的預設貨幣，例如「Balance · TWD」。每一列是一位成員的淨額，正數綠色、負數紅色，你自己會顯示為「你」。右上角有「**統計**」連結。

### To Settle（待結清）

把上面的餘額換算成「誰轉給誰、多少錢」。每一筆右下角有「**已轉**」按鈕，點下去確認後會自動記成一筆還款，餘額即時更新。

### Expenses（費用列表）

依月份分組列出**所有**費用（不像 `/list` 只有 10 筆），由新到舊。每一列顯示付款人頭像、說明、金額與日期，點進去就是編輯頁。

**還款也會出現在同一個清單裡**，顯示成「A → B」並帶一個 🤝 圖示，點進去是還款的編輯頁。費用和還款混在一起按時間排，這樣一趟旅程的來龍去脈可以一路往下看完。

清單上方有兩個顯示選項：

| 選項 | 作用 |
| --- | --- |
| **總額 / 淨額** | 「總額」顯示每筆的完整金額；「淨額」改成顯示這筆**對你個人**的影響（正數代表別人欠你、負數代表你欠別人） |
| **只看我的** | 只留下和你有關的紀錄 |

這兩個選項會記在你的裝置上，下次打開還是同一個設定。

右上角有兩顆新增按鈕：「**＋ 還款**」記一筆還款，「**＋ 新增**」記一筆費用。

### 全部結清時

當所有人的餘額都歸零，Balance 與 To Settle 區塊會收起來，改成一塊綠色的「**所有帳款已結清**」，並附上「統計」連結。下方的 Expenses 清單仍然完整保留所有費用與還款。

## 餘額是怎麼算出來的？

規則其實只有一條：

1. 你**付出去**的錢 → 計為正
2. 你**該分攤**的錢 → 計為負

淨額 = 兩者相加。

還款不需要另外一套邏輯——在系統裡，一筆「A 還 B 300」就是一筆特殊的費用：A 是唯一的付款人、B 是唯一的分擔者。套進上面同一條規則，剛好就是 A +300、B −300，正好抵銷兩人之間的欠款。

只要涉及不同幣別，都會先換算成群組的預設貨幣再加總，換算用的匯率依序是：這筆自己鎖定的匯率 → 群組的自訂匯率 → 當天的市場匯率。詳見 [多幣別](/help/multi-currency)。

> 記一筆還款**不會**修改或刪除任何費用。費用的歷史永遠完整保留，隨時可以回頭查。
