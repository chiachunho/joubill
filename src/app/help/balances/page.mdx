# 查看帳務

## `/balance`：每個人的淨額

在群組輸入 `/balance`，機器人會列出帳本中每位成員的**淨餘額**，應收的在前、應付的在後：

```
💰 日本行　餘額（TWD）
・Alice 應收 1,200
・Bob 應付 450
・你 應付 750
```

- **應收**：你先幫大家墊了錢，別人要還你
- **應付**：你還欠別人錢

已經完全結清（餘額為零）的人不會出現在清單上。整個群組都結清時，機器人會回「大家都結清了 🎉」。

訊息下方的「**怎麼還**」會接著列出還款建議（同 `/settle`）。

在跟機器人的**私訊**裡打 `/balance`，會一次列出你在每個群組的餘額（各用該群組的幣別），點群組名稱看那個群組的完整明細：

```
你的餘額
・日本行 應收 1,200 TWD
・室友 應付 300 TWD
・公司午餐 已結清
```

## `/list`：最近的紀錄

在群組輸入 `/list`，顯示最近 **10 筆**紀錄（支出和還款都有），依日期由新到舊：

```
最近 3 筆
07/12　晚餐 1,200 · @alice
07/11　💸 Bob → Alice 450
07/10　拉麵 3,000 JPY · 你
```

支出那行是**日期**、**說明**、**金額**、**付款人**；還款那行是**誰 → 誰**和金額。金額是群組預設貨幣時不另外標幣別。多人共付時會列出所有付款人。

還沒有任何紀錄時，機器人會提示「還沒有紀錄，試試 `/add 50 飲料`」。

## `/settle`：還款建議

在群組輸入 `/settle`，機器人會算出**次數最少**的還款方案：

```
🤝 日本行　怎麼還（TWD）
Bob → Alice 450
你 → Alice 750
還完在 App 記一筆還款
```

演算法每次都拿「欠最多的人」去還「被欠最多的人」，盡量把多筆零碎欠款合併成一次轉帳。金額以群組的**預設貨幣**顯示。還完後點「**開啟揪帳**」記一筆還款。

全部結清時會回「大家都結清了 🎉」。

> `/list`、`/settle`、`/export` 也能在私訊用：你在好幾個群組時，機器人會先問是哪個群組。私訊裡的 `/export` 會把 CSV 傳給你自己，不會出現在群組（見[匯出](/help/export)）。

## 圖形介面的群組主頁

在 Mini App 或網頁版開啟群組後，主頁由三個區塊組成：

### 餘額

標題會帶上群組的預設貨幣，例如「餘額 · TWD」。每一列是一位成員的淨額，正數綠色、負數紅色，你自己會顯示為「你」。右上角有「**統計**」連結。

### 待還款

把上面的餘額換算成「誰轉給誰、多少錢」。每一筆右下角有「**標記已還**」按鈕，點下去確認後會自動記成一筆還款，餘額即時更新。

### 紀錄

依月份分組列出支出（不像 `/list` 只有 10 筆），由新到舊。一次先載入最近 30 筆，往下捲到底會自動載入更早的紀錄；如果沒有自動載入，列表底部會出現「載入更多」按鈕。每一列顯示付款人頭像、說明、金額與日期，點進去就是編輯頁。

**還款也會出現在同一個清單裡**，顯示成「A → B」並帶一個還款圖示（手拿錢幣），點進去是還款的編輯頁。支出和還款混在一起按時間排，這樣一趟旅程的來龍去脈可以一路往下看完。

清單上方有兩個顯示選項：

| 選項            | 作用                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------- |
| **總額 / 淨額** | 「總額」顯示每筆的完整金額；「淨額」改成顯示這筆**對你個人**的影響（正數代表別人欠你、負數代表你欠別人） |
| **只看我的**    | 只留下和你有關的紀錄（只會篩選已載入的部分，往下捲會繼續載入更早的）                                     |

這兩個選項會記在你的裝置上，下次打開還是同一個設定。

右上角有兩顆新增按鈕：「**＋ 還款**」記一筆還款，「**＋ 支出**」記一筆支出。

### 全部結清時

當所有人的餘額都歸零，「餘額」與「待還款」區塊會收起來，改成一塊綠色的「**所有帳款已結清**」，並附上「統計」連結。下方的「紀錄」清單仍然完整保留所有支出與還款。

## 餘額是怎麼算出來的？

規則其實只有一條：

1. 你**付出去**的錢 → 計為正
2. 你**該分攤**的錢 → 計為負

淨額 = 兩者相加。

還款不需要另外一套邏輯——在系統裡，一筆「A 還 B 300」就是一筆特殊的支出：A 是唯一的付款人、B 是唯一要分攤的人。套進上面同一條規則，剛好就是 A +300、B −300，正好抵銷兩人之間的欠款。

只要涉及不同幣別，都會先換算成群組的預設貨幣再加總，用哪個匯率見[多幣別](/help/multi-currency#跨幣別的餘額怎麼計算)。

> 記一筆還款**不會**修改或刪除任何支出。支出的歷史永遠完整保留，隨時可以回頭查。
