# 快速入門

## 揪帳是什麼？

揪帳是一款 Telegram 群組分帳工具，讓你在聚餐、旅遊、日常代購時，輕鬆記錄支出並算出每個人該付多少。

- **記帳快**：在群組直接打 `/add` 指令，一行搞定一筆
- **算得清**：自動計算誰欠誰多少，並建議次數最少的還款方式
- **功能齊**：多幣別、多人共付、五種分帳方式、收據照片
- **兩種介面**：Telegram 裡的 Mini App，以及瀏覽器上的網頁版

---

## 怎麼開始？

### 大家都在同一個 Telegram 群組

1. 在 Telegram 找到揪帳機器人，把它**加進你要分帳的群組**
2. 機器人加入後會自動打招呼，並附上「**開啟揪帳**」按鈕
3. 直接輸入 `/add 300 午餐` 記下第一筆，或按按鈕進入圖形介面

> 如果機器人沒有自動打招呼，在群組輸入 `/start` 也會叫出同一則歡迎訊息。

### 有人不用 Telegram，或還沒有群組

1. 用瀏覽器打開揪帳網頁版並登入。除了 Telegram，網站有開放的話也能用 Google、LINE 或 GitHub（見[登入與帳號](/help/account)）
2. 在「我的群組」按「**建立群組**」，填名稱和預設貨幣（見[群組設定](/help/group-settings#建立群組)）
3. 用邀請連結或邀請碼請朋友加入；不想註冊的人，可以直接新增成沒有帳號的成員（見[成員](/help/members)）

之後想讓帳目也出現在某個 Telegram 群組裡，再用 `/link` 綁定就好。

## 誰會被自動加入帳本？

帳本裡的成員是**慢慢累積**出來的：用過機器人、被拉進群組的人會自動登記，**只是在群組聊天並不會**。所以剛開始帳本裡可能只有你一個人，這是正常的。

最快的做法是請朋友點一下機器人訊息上的「**開啟揪帳**」，就會把自己加進來；其他人可以回覆他的訊息打 `/join` 補上。完整的規則見[成員](/help/members)。

## 兩種使用介面

除了機器人指令之外，揪帳提供兩個功能相同的圖形介面：

| 介面         | 怎麼進入                                              | 適合                   |
| ------------ | ----------------------------------------------------- | ---------------------- |
| **Mini App** | 在群組輸入 `/app`，或點機器人訊息上的「開啟揪帳」按鈕 | 在 Telegram 裡直接操作 |
| **網頁版**   | 用瀏覽器開啟揪帳網站並登入                            | 在電腦上整理帳目       |

兩邊看到的是同一份資料，畫面與功能也一致；少數只有網頁版能做的事，以及登入方式，見[登入與帳號](/help/account)。

## 指令一覽

在**群組**裡可以用：

| 指令        | 說明                               |
| ----------- | ---------------------------------- |
| `/add`      | 記一筆（例如 `/add 500 晚餐`）     |
| `/list`     | 最近 10 筆紀錄                     |
| `/balance`  | 誰應收、誰應付                     |
| `/settle`   | 怎麼還最省事                       |
| `/export`   | 匯出 CSV                           |
| `/join`     | 回覆某人打 `/join` 把他加進來      |
| `/link`     | 綁定網頁建立的群組                 |
| `/timezone` | 群組時區（決定 `/add` 記在哪一天） |
| `/topic`    | 通知發到哪個主題（開了主題的群組） |
| `/unlink`   | 解除綁定（機器人會離開）           |
| `/app`      | 開啟揪帳                           |
| `/help`     | 指令說明                           |

在**與機器人的私訊**裡可以用 `/start`、`/help`、`/app`，以及 `/add`、`/balance`、`/settle`、`/list`、`/export`。你在好幾個群組時，機器人會先問是哪個群組；私訊的 `/balance` 會一次列出你在每個群組的餘額。

> 要記住的語法只有 `/add 金額 說明` 這一行。誰付、誰要分、份數怎麼算、換什麼幣別，全部都在記完之後那則訊息下方的「**☰ 調整**」按鈕裡，不用背指令。

> 機器人送出的訊息都設定為靜音，不會發出通知音效，記帳時不會一直打擾群組。

## 之後想再看這份說明？

三個地方都找得到：

- 在群組打 `/help`，訊息下方有「**完整使用說明**」按鈕
- 機器人的歡迎訊息（`/start`）上也有同一顆按鈕
- Mini App 或網頁版：「我的群組」頁右上角的人像圖示 →「個人設定」→ 關於 →「**使用說明**」
