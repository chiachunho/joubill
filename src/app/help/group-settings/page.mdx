# 群組設定

在 Mini App 或網頁版進入群組，點右上角的**齒輪圖示**就是「**群組設定**」。最上面是成員（見[成員](/help/members)），下面依序是：

| 項目              | 做什麼                                             | 說明                                                   |
| ----------------- | -------------------------------------------------- | ------------------------------------------------------ |
| **Telegram 群組** | 綁定或解除綁定 Telegram 群組、記帳通知發到哪個主題 | 本頁                                                   |
| **貨幣與匯率**    | 預設貨幣、群組時區、自訂匯率                       | 本頁的時區；貨幣與匯率見[多幣別](/help/multi-currency) |
| **通知**          | 這個群組要不要推播給你（網頁版）                   | [加到主畫面與通知](/help/add-to-home-screen)           |
| **動態紀錄**      | 整個群組的新增、修改、刪除紀錄                     | [記帳](/help/adding-expenses#動態紀錄)                 |
| **匯出**          | CSV 和 Beancount                                   | [匯出](/help/export)                                   |
| **刪除群組**      | 永久刪除整個群組                                   | 本頁                                                   |

---

## 建立群組

1. 在網頁版或 Mini App 的「我的群組」頁按「**建立群組**」
2. 填入**群組名稱**，選好**預設貨幣**
3. 按「建立群組」，你就是第一位成員，直接進到群組主頁開始記帳

網頁建立的群組**沒有 Telegram 聊天室**：記帳、編輯、刪除不會在聊天室裡發訊息，群組頭像會用名稱的首字代替。其他功能（分帳、餘額、還款、統計、匯出）都和一般群組一樣。

---

## 綁定 Telegram 群組

想讓網頁建立的群組也在 Telegram 聊天室裡出現記帳卡片，在那個 Telegram 群組輸入：

```
/link K7M2Q-X9PAB
```

不用自己去找邀請碼：群組設定 →「**Telegram 群組**」那一列的「**如何綁定**」會直接顯示這個群組的指令，按「**複製**」貼到聊天室就好；群組還沒有邀請碼時，先按「**產生邀請碼**」。邀請碼也可以在群組設定成員清單最下方的「**＋ 新增成員**」→「**用邀請碼邀請**」看到。綁定後，之後的記帳會在聊天室出現卡片，群組頭像也會同步。

- 你必須已經是這個網頁群組的成員；邀請碼只用來找到群組，不會讓你加入
- 一個群組只能綁一個聊天室，已經綁定的不能再綁
- 如果這個聊天室已經用 `/add` 記過帳，兩邊都有帳目，沒辦法自動合併，所以會被拒絕。**建議先 `/link` 再開始記帳**
- 綁定前的舊紀錄不會補發到聊天室
- 聊天室裡還沒在群組的人，會在使用機器人時自動加入，或用 `/join` 補進來
- 邀請碼打錯、已被重設，或你不是成員，機器人的回覆都是同一句「邀請碼無效或已失效」

## 解除 Telegram 群組綁定

綁錯聊天室、聊天室不用了，或想在同一個聊天室重新開始，都可以解除綁定。任何成員都可以操作，兩個地方擇一：

- **在 App**：群組設定 →「**Telegram 群組**」那一列右邊的「**解除綁定**」，確認後生效
- **在聊天室**：輸入 `/unlink`，機器人會先問一次，按「✗ 解除綁定」才會執行

解除後：

- 群組變回一般的網頁群組，**成員、所有紀錄和邀請碼都保留**
- 之後的記帳不再發到聊天室；聊天室裡舊的卡片不會再更新，上面的按鈕也不能用了
- **機器人會在聊天室留一句話，然後離開那個群組**
- 動態頁會記下誰在什麼時候解除了哪個聊天室

之後想再綁定：

- 綁回同一個或另一個聊天室：先把機器人加回聊天室，再輸入 `/link 邀請碼`
- 這個聊天室想重新開始：把機器人加回來，第一次有人用機器人時就會建立一個新的空群組。想把它蓋成某個舊群組，在有人記帳**之前**輸入 `/link 邀請碼`；已經記過帳就不能自動合併了

在 Telegram 建立的群組也能解除；解除後帳本留在 App 裡，聊天室則可以重新開始。

## 記帳通知發送位置（主題）

Telegram 群組開啟「主題」（Topics）功能後，可以指定一個主題，讓記帳通知集中在那裡，不會洗掉其他聊天。

會發到指定主題的是**沒有對話可回**的訊息：

- 在 Mini App、網頁版或連結的應用程式新增的記帳卡片和還款通知
- 從 App 傳到群組的 CSV 匯出檔、刪除群組的公告

在群組裡打的指令（`/add`、`/balance`…）**回覆會留在打指令的地方**，在哪個主題打就回在哪個主題。修改和刪除也一樣：卡片會在原本的位置更新。

### 怎麼設定

Telegram 機器人沒辦法列出群組有哪些主題，所以要在 Telegram 裡選：

1. 到想要的主題裡輸入 `/topic`
2. 按機器人回覆裡的「**改發到「主題名稱」**」

要改回 General，在 `/topic` 的回覆裡按「**↺ 改回 General**」，或到**群組設定 → Telegram 群組 → 記帳通知發送位置**按「改回 General」。群組沒有開啟主題功能時，這個設定不會出現。

任何成員都可以改，每次修改都會記在「動態紀錄」裡。如果指定的主題被刪除或關閉，機器人會在 General 說一聲，之後的通知改發在 General。

## 群組時區

每個群組有一個「時區」，預設是 Asia/Taipei（台北，UTC+8）。它只做兩件事：

1. 決定機器人的 `/add` 在你沒有指定日期時，把支出記在**哪一天**——也就是這個時區的「今天」。
2. 決定查匯率時「今天」是哪一天。

它**不會**改變已經記好的紀錄：每一筆紀錄的日期就是你記帳時選的那一天，之後改時區也不會動。

任何成員都可以改，三個地方都行：

- **建立群組時**：時區預設為你裝置目前的時區，可以直接改。
- **群組設定 → 貨幣與匯率 → 時區**（Mini App 和網頁版都有）：選好之後會先確認，因為這會影響整個群組。
- **在群組輸入 `/timezone`**：機器人列出常用的時區（例如 `Asia/Taipei (UTC+8)`、`Asia/Tokyo (UTC+9)`），點一下就改好；其他時區請到群組設定選。

出國旅行時，如果你的裝置時區和群組的時區 UTC 偏移不同，進入群組頁會問你要不要改成裝置的時區。選「不用」之後，這台裝置不會再問，除非你的裝置時區又換了。偏移相同的時區（例如台北和新加坡）不會問。

每次修改都會記在群組的「動態紀錄」裡。

## 群組名稱和頭像

直接同步自 Telegram，不需要另外設定。（網頁建立的群組沒有 Telegram 聊天室，名稱在建立時決定，頭像用名稱的首字。）群組改名或換頭像後，下次有人和機器人互動時就會自動更新。

如果群組從一般群組被升級成**超級群組**（supergroup），Telegram 會換一組新的群組編號。機器人會自動跟著換過去，原本的成員和帳目都會保留，不需要重新設定。

## 刪除整個群組

在「群組設定」最下面有一列紅字的「**刪除群組**」。刪除後所有支出與還款紀錄都會**永久清除**，而且機器人會自動離開這個 Telegram 群組（[網頁建立的群組](#建立群組)沒有聊天室，所以沒有這一步）。

流程依群組人數而不同：

**帳本只有你一個人** — 確認後立即刪除。

**帳本有多位成員** — 需要另一位成員同意，避免一個人就把大家的帳全部刪掉：

1. 你按下「刪除群組」，送出一則**刪除申請**
2. 機器人會在 Telegram 群組發訊息公告，附上「**✓ 同意刪除**」和「**✗ 拒絕**」兩個按鈕
3. 其他成員可以在 Telegram 訊息上直接按，或在群組主頁頂端的提示（也可以在「群組設定」最下面那一列）裡按「同意刪除」／「拒絕」
4. 只要**任何一位其他成員同意**，群組就會立刻刪除，機器人也會離開群組

申請送出後，你自己會在「群組設定」最下面那一列看到「等待其他成員確認」，隨時可以按「**取消申請**」撤回。其他成員也可以按「拒絕」把申請擋下來。

> 幾個要注意的地方：申請者**不能同意自己的申請**；申請 **48 小時**後會自動失效，過期後需要重新申請；刪除之後資料無法復原。

### 網頁建立的群組

流程和一般群組相同（單人直接刪除，多人需要另一位成員同意），差別在於沒有 Telegram 聊天室可以按按鈕。申請送出後，其他成員打開群組主頁會看到「**申請刪除此群組**」的提示，可以直接按「**同意刪除**」或「**拒絕**」。

## 常見問題

**可以把某個群組的支出搬到另一個群組嗎？**

目前不行，支出會固定屬於建立時的群組。
