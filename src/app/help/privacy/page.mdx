# 隱私權政策

生效日期：2026 年 11 月 1 日

揪帳（Joubill，以下稱「本服務」）是一個分帳工具，包含 Telegram 機器人、Telegram Mini App 及網頁版，由個人開發者（以下稱「我們」）開發與維運。本政策說明我們蒐集哪些資料、如何使用，以及你可以如何控制它們。

## 1. 我們蒐集的資料

**帳號資料**（依你使用的登入方式而定）：

| 來源                                        | 資料                                                                                                                              |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Telegram（機器人、Mini App、Telegram 登入） | Telegram 使用者 ID、名字、姓氏、使用者名稱（@username）、大頭貼、語言設定；以網頁版 Telegram 登入時另有登入時核發的憑證           |
| Google / GitHub / LINE 登入                 | 該服務的帳號識別碼、名稱、大頭貼網址、登入時核發的 OAuth 憑證；Google 與 GitHub 另有電子郵件（若有提供；LINE 的電子郵件不會保存） |
| 你自行設定                                  | 顯示名稱、要使用哪一個大頭貼                                                                                                      |

**你和群組成員輸入的帳務資料**：群組名稱、成員名單、每筆支出與還款的金額、幣別、說明、日期、付款人與分攤方式、自訂匯率、收據照片，以及你為群組建立的「沒有帳號的成員」名稱。

**操作紀錄**：每筆紀錄的新增、修改與刪除，會記下是誰、從哪裡（機器人、App 或連結的應用程式）、何時操作，以及修改前後的內容。這是為了讓群組裡任何人都能修正錯誤，同時保留可追查的紀錄。

**連結的應用程式**：你在「個人設定 → 連結的應用程式」建立的連線，會記下名稱、權限、可存取的群組、到期日與最後使用時間；個人存取權杖與 OAuth 授權的存取權杖都只保存不可逆雜湊，無法還原；OAuth 登錄時第三方應用程式自行提供的名稱與回呼網址也會保存，用來在授權頁與紀錄中顯示。透過它記下的紀錄，操作紀錄會標明是哪個應用程式。

**Telegram 群組訊息**：機器人在群組中預設只會收到指令（例如 `/add`）、提及機器人的訊息，以及回覆機器人的訊息，不會讀取其他聊天內容。我們會記錄群組的 Chat ID 與成員加入、離開的事件，以維護成員名單。

**裝置與技術資料**：

- 登入用的 Session Cookie（必要，用於維持登入狀態）。
- 若你開啟推播通知：瀏覽器提供的推播訂閱端點與金鑰。
- 防止猜測邀請碼：查詢或使用邀請碼時，我們會記錄嘗試次數，以帳號以及你 IP 位址經過不可逆雜湊後的值為單位。不保存 IP 位址本身，這些計數最多保留一天。
- 瀏覽器本機儲存（localStorage / sessionStorage）：例如「下次再說」等提示的選擇，只存在你的裝置上。
- Vercel Web Analytics 與 Speed Insights：匿名的瀏覽量與頁面效能統計，不使用追蹤 Cookie，不用來識別個人。

## 2. 我們如何使用資料

- 提供分帳功能：計算餘額、建議結清方式、顯示統計、匯出 CSV 與 Beancount。
- 辨識你的身分，讓同一個人用不同方式登入時對應到同一個帳號（包含你主動發起的帳號連結與合併）。
- 在 Telegram 群組中發送與更新紀錄訊息，並在你開啟時發送推播通知。
- 維護服務的安全與穩定、排除錯誤。

我們**不會**販售你的資料，**不會**用於廣告，也不會用來訓練任何模型。

## 3. 誰看得到你的資料

- **同群組的成員**：可以看到你在該群組的名稱、大頭貼、帳務紀錄與操作紀錄。所有成員都能編輯或刪除群組內的任何紀錄。
- **Telegram 群組**：若群組綁定了 Telegram 聊天室，紀錄會以訊息形式發到該聊天室，聊天室成員都看得到。
- **持有邀請碼的人**：登入後可以看到群組名稱、成員人數，以及「沒有帳號的成員」的名稱，以便選擇自己是誰；看不到帳務紀錄。
- **你連結的應用程式**：你在「連結的應用程式」授權的第三方服務（例如 Claude、ChatGPT、n8n），會讀取你所選群組的資料；若你給了「可記帳」，還可以新增、修改與刪除那些群組的紀錄。這些資料到了該服務之後，依該服務自己的隱私權政策處理，我們管不到。你可以隨時撤銷授權。
- **其他使用者**：不在同一群組的人看不到你的帳務資料。

## 5. Google 使用者資料

若你使用 Google 登入，我們只要求 `openid`、`email`、`profile` 範圍，取得你的 Google 帳號識別碼、名稱、電子郵件與大頭貼，僅用於登入、帳號連結與顯示你的大頭貼。登入時 Google 核發的憑證（存取權杖等）會和登入方式一起保存，但我們不會用它呼叫任何 Google API；解除該登入方式的連結時一併刪除。本服務對 Google API 所取得資料的使用與轉移，遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包含其中的 Limited Use 要求。我們不會將這些資料轉移給第三方，也不會用於廣告。

## 6. 資料保存期間

- 帳務紀錄與操作紀錄：保存到群組被刪除為止。刪除單筆紀錄後，操作紀錄中仍會保留該筆的內容，作為群組的稽核紀錄。
- 群組刪除後（有其他擁有帳號的成員時需要其中一位同意），該群組的紀錄、操作紀錄與「沒有帳號的成員」會一併刪除。收據照片存放在 Telegram，已發到 Telegram 群組的訊息也留在該聊天室，這兩者不會隨之刪除。
- 登入 Session 到期後失效；推播訂閱在你關閉通知、登出或推播服務回報失效時刪除。
- 暫時性的機器人等待狀態超過 24 小時即失效、帳號合併憑證超過 10 分鐘即失效，並在之後的操作中清除。

## 7. 你的權利

你可以隨時：

- 在「個人設定」修改顯示名稱與大頭貼、解除登入方式的連結（Telegram 與最後一個登入方式除外）、關閉推播通知。
- 匯出群組的紀錄（CSV）。
- 來信要求查詢、更正或刪除你的帳號資料：<ContactEmail />。

刪除帳號時，你在群組中的歷史紀錄會影響其他成員的餘額，因此我們可能會保留這些紀錄，但移除可識別你身分的帳號資料（例如登入方式、電子郵件、大頭貼）。你亦享有適用之個人資料保護法規賦予的其他權利。

## 8. 安全

所有連線皆使用 HTTPS；Telegram 的身分資料會經過簽章驗證；機器人金鑰不會出現在任何用戶端網址中。但沒有任何系統能保證絕對安全。
