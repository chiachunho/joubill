# 記帳（加入費用）

## 用 Bot 指令快速記帳

### 全群均分

在群組輸入：

```
/add 600 聚餐
```

機器人會把這筆費用平均分給帳本裡的**所有成員**，並記錄你（發送者）為付款人。金額除不盡時，餘數會逐分分配給前面幾個人，加總永遠等於總額。

記完後，機器人會回覆一則訊息，附上「**編輯**」「**上傳收據**」「**刪除**」三個按鈕。

---

### 只分給特定人

```
/add 300 早餐 @alice @bob
```

只會平均分給 alice 和 bob，其他成員不納入這筆費用。

> 沒有設定 username 的人無法用 `@名字` 打出來，請改用 Telegram 的**提及選單**（輸入 `@` 後從清單點選），機器人同樣能識別，而且會順便把對方登記進帳本。

---

### 多人各付不同金額（多行分帳）

第一行寫總金額與說明，接下來每行指定一個人要分擔多少：

```
/add 800 聚餐
@alice 300
我 500
```

每一行的格式是「`@使用者名稱 金額`」或「`我 金額`」（也可以用 `me`），也可以從提及選單點選沒有 username 的人再接金額。

**沒被指定到的成員**，系統會把剩下的金額平均分給他們。例如群組有四個人、總額 800、只指定了 alice 300，那剩下的 500 就由其他三人平分。

也可以**不寫總金額**，讓系統直接加總：

```
/add 聚餐
@alice 300
我 500
```

這樣總額就是 800。

> 兩種情況機器人會回報錯誤：指定的金額**加總超過總額**，或是還有剩餘金額、但**每個成員都已經被指定**（沒有人可以分攤剩下的錢）。

---

### 不確定格式？直接打 `/add`

只輸入 `/add` 不帶任何參數，機器人會回一則提示訊息，你直接**回覆**它並輸入內容即可，格式與上面完全相同（不用再打一次 `/add`）。

---

### 附上收據照片

**方法一：傳照片時在說明欄輸入指令**

在 Telegram 選好照片，於說明（caption）欄位輸入：

```
/add 480 超市採購
```

送出後費用與收據一次完成。

> Caption 模式只支援**全群均分**：不能用多行分帳指定金額、不能 `@` 特定成員，也不能一次傳多張照片。需要更細的分帳時，請改用純文字 `/add` 或圖形介面。

**方法二：事後補傳**

純文字 `/add` 記錄的費用，訊息上會有「**上傳收據**」按鈕。點下去後機器人會請你「回覆這則訊息並附上收據照片」，回傳一張照片即可完成綁定。

> Bot 流程每筆費用只能存**一張**收據。想要一筆費用附多張收據，請到 Mini App 或網頁版編輯該筆費用，最多可以放 **5 張**。

## 用圖形介面記帳（完整選項）

在 Mini App 或網頁版的群組主頁，點 Expenses 區塊右上角的「**＋ 新增**」，進入「新增支出」頁面。欄位由上到下依序是：

### 金額與幣別

輸入金額並選擇幣別，預設為群組的預設貨幣。詳見 [多幣別](/help/multi-currency)。

### 日期

預設為今天，點日期按鈕可以改成過去的日期，方便補記。這個日期也決定了外幣換算要用哪一天的匯率。

### 說明

選填，最多 500 字。

### 收據

點「**附上收據照片**」選取照片，最多 5 張，上傳中會顯示「上傳中…」。點縮圖可以放大檢視，也可以逐張移除。

### 付款人

預設是你自己。若是多人共付（例如兩個人各刷了一張卡），點「**新增付款人**」切換成多人模式，勾選付款的人並分別填金額。畫面下方會即時顯示「已付 X / 總額」，**加總必須等於總金額**才能儲存。

### 分帳方式

共五種：

| 方式 | 你要輸入什麼 | 怎麼算 |
| --- | --- | --- |
| **均分** | 不用輸入 | 所有參與者平均分，餘數逐分分配 |
| **指定** | 每人的金額 | 直接採用，加總需等於總金額 |
| **比例** | 每人的百分比 | 依比例換算，加總需為 100% |
| **份數** | 每人的份數 | 依份數比例分配，留空預設為 1 份 |
| **調整** | 每人**額外**負擔的金額 | 先扣掉所有額外金額，剩下的平均分，再各自加回自己的額外金額 |

「調整」適合「大致均分，但某幾個人要多付一點」的情況——例如某人多點了一份甜點，就在他那一列填甜點的錢，剩下的餐費仍然大家平分。額外金額的加總不能超過總金額。

### 參與者

勾選誰要分擔這筆費用。停用中的成員仍然會出現在清單裡，只是預設不勾選。畫面下方的狀態列會即時顯示加總是否平衡，不平衡時無法儲存。

---

## 修改或刪除費用

在群組主頁的 Expenses 清單點任一筆費用，會**直接進入編輯頁**（沒有另外的詳情頁），所有欄位都可以修改，改完按「儲存」餘額就會立即重算。

- **修改**：群組裡的**任何成員**都可以編輯費用
- **刪除**：只有這筆費用的**建立者**可以刪除。編輯頁下方有「刪除」按鈕，也可以按機器人訊息上的「刪除」

> 為什麼修改沒有限制、刪除卻有？因為改錯了還能再改回來，刪掉卻救不回來。若你不是建立者但這筆費用需要刪除，請對方協助，或直接把金額與分擔改成正確的內容。
