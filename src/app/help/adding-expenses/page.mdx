# 記帳（加入費用）

## 用 Bot 指令快速記帳

### 基本用法

在群組輸入：

```
/add 金額 說明
```

例如：

```
/add 600 聚餐
```

機器人會把這筆費用平均分給帳本裡的**所有成員**，並記錄你（發送者）為付款人。

---

### 只分給特定人

```
/add 300 早餐 @alice @bob
```

只會平均分給 alice 和 bob，其他成員不納入這筆費用。

> 沒有 Telegram 帳號的人，可以用 Telegram 的「**提及**」功能（@name 選單）點選，機器人同樣能識別。

---

### 多人各付不同金額

先發送：

```
/add 600 聚餐
```

再**回覆**機器人的確認訊息，依格式輸入每人金額：

```
@alice 250
@bob 200
@carol 150
```

機器人會依你指定的金額分配，各人加總必須等於總額。

---

### 附上收據照片

**方法一：直接在 `/add` 附圖**

在 Telegram 選擇照片，在說明欄輸入：

```
/add 480 超市採購
```

一次完成，機器人會自動把照片存為收據。

**方法二：事後補傳**

費用記錄後，點選機器人訊息的「**上傳收據**」按鈕，再直接回傳照片即可。每筆費用最多可附 **5 張**收據照片。

---

## 用 Mini App 記帳（更多選項）

在 Telegram 開啟 Mini App 後，點「**＋**」新增費用，可以設定：

### 付款人

預設為你自己。若是多人共付（例如兩個人各刷了一張卡），可以點「**新增付款人**」，分別輸入每人付的金額。兩人加總必須等於總費用。

### 分帳模式

| 模式 | 說明 | 適合情境 |
| --- | --- | --- |
| **均分** | 所有參與者平均分 | 大家消費差不多 |
| **各自輸入** | 每人輸入自己的金額 | AA 但各點不同餐點 |
| **份數** | 設定份數比例（如 2:1） | 帶了一個人份量多 |
| **百分比** | 設定每人佔比（加總需 100%） | 按比例分攤 |
| **調整均分** | 先均分，再對每人加減 | 大部分均分，個別微調 |

### 參與者

點選或取消點選成員，決定誰要分這筆費用。

### 日期

預設為今天。可以點選日期按鈕修改，方便補記過去的費用。

### 收據

點「**上傳**」選取照片，最多 5 張。

---

## 修改或刪除費用

- **刪除**：只有費用的**建立者**可以刪除。在機器人訊息按「刪除」，或在 Mini App 費用詳情頁按「刪除費用」。
- **修改**：在 Mini App 點開費用，再按「編輯」，可修改所有欄位。
