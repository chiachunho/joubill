# 記帳（加入費用）

## 用 Bot 指令快速記帳

### 基本用法

在群組輸入：

```
/add 金額 說明
```

例如：

```
/add 600 聚餐
```

機器人會把這筆費用平均分給帳本裡的**所有成員**，並記錄你（發送者）為付款人。

---

### 只分給特定人

```
/add 300 早餐 @alice @bob
```

只會平均分給 alice 和 bob，其他成員不納入這筆費用。

> 沒有 Telegram 帳號的人，可以用 Telegram 的「**提及**」功能（@name 選單）點選，機器人同樣能識別。

---

### 多人各付不同金額（多行分帳）

直接輸入 `/add`（不加任何參數），機器人會用 ForceReply 提示你輸入內容；或是直接用多行格式一次送出：

```
/add 800 聚餐
@alice 300
我 500
```

第一行是總金額與說明，接下來每一行指定一人要付的金額。沒被指定的人，系統會把剩餘金額平均分給他們；若每個人都已指定，加總就是這筆費用的總額。

> 若你指定的金額加總超過總額，機器人會回報錯誤，請檢查後重新輸入。

---

### 附上收據照片

**方法一：直接在 `/add` 附圖**

在 Telegram 選擇照片，在說明欄輸入：

```
/add 480 超市採購
```

一次完成，機器人會自動把照片存為收據。

> 用照片 + caption 記帳時，僅支援「全群均分」這種最簡單的分法：不能用多行分帳指定金額，也不能 @ 特定成員，更不支援一次傳多張照片。若需要更精細的分帳或多張收據，請改用文字 `/add` 或 Mini App。

**方法二：事後補傳**

純文字 `/add` 記錄的費用，機器人訊息會附上「**上傳收據**」按鈕；點選後直接回傳照片即可完成綁定。

> Bot 流程下每筆費用只能附**一張**收據照片；若要一筆費用附多張收據，請到 Mini App 編輯該筆費用上傳（最多 5 張）。

---

## 用 Mini App 記帳（更多選項）

在 Telegram 開啟 Mini App 後，在群組主頁點「**＋ 新增**」，即可進入「新增支出」頁面設定：

### 付款人

預設為你自己。若是多人共付（例如兩個人各刷了一張卡），可以新增付款人，分別輸入每人付的金額。所有付款人的金額加總必須等於總費用。

### 分帳模式

| 模式 | 說明 | 適合情境 |
| --- | --- | --- |
| **均分** | 所有參與者平均分 | 大家消費差不多 |
| **指定** | 每人輸入自己的金額 | AA 但各點不同餐點 |
| **比例** | 設定每人佔比（加總需 100%） | 按比例分攤 |
| **份數** | 設定份數比例（如 2:1） | 帶了一個人份量多 |
| **調整** | 先均分，再對每人加減 | 大部分均分，個別微調 |

### 參與者

點選或取消點選成員，決定誰要分這筆費用。

### 日期

預設為今天。可以點選日期按鈕修改，方便補記過去的費用。

### 收據

點「**附上收據照片**」選取照片，每筆費用最多可附 **5 張**收據照片。

---

## 修改或刪除費用

在 Mini App 主頁點選任一筆費用，會直接進入「編輯支出」頁面，所有欄位都可以修改。

- **修改**：直接調整任何欄位後儲存即可。
- **刪除**：頁面下方有「**刪除**」按鈕，但只有費用的**建立者**可以刪除；非建立者請請建立者協助操作。
