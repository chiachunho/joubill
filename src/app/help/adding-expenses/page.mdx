# 記帳（加入支出）

## 用機器人記帳

### 只要記一行

```
/add 500 晚餐
```

這是唯一需要記住的語法：**`/add 金額 說明`**。機器人會把支出平均分給帳本裡的所有成員，並記錄你為付款人。

機器人會回一張卡片，第一行是「說明　誰 付 金額」，下面每人一行，寫這個人分多少：

```
晚餐　小明 付 600 TWD
・小明 200
・阿華 200
・Amy 200
```

多人共付的支出（在 App 裡設定），每行會寫這個人付了多少、分多少，例如「・小明 付 3,000，分 1,250」。

卡片下方有三顆按鈕：

| 按鈕        | 作用                                 |
| ----------- | ------------------------------------ |
| **☰ 調整** | 改誰付、誰要分、份數、幣別、金額     |
| **⊕ 收據**  | 補傳收據照片（已經有收據時不會出現） |
| **⊗ 刪除**  | 刪掉這筆                             |

> 誰付、誰要分、份數、幣別這些都**不是指令語法**，而是按鈕。不用背，記完再點開調整就好。

---

### 金額怎麼寫都行

機器人會盡量讀懂你寫的金額：

| 你可以寫                 | 會被讀成 |
| ------------------------ | -------- |
| `1,200`                  | 1200     |
| `300元`、`300塊`、`$300` | 300      |
| `3k`、`3千`              | 3000     |
| `1.5w`、`1.5萬`          | 15000    |
| `150+200`                | 350      |
| `(300+150)/3`            | 150      |

全形數字和符號（`５００`、`＋`）也可以。加減乘除都支援。

> 金額後面要接空白，所以 `3杯咖啡` 不會被當成 3——機器人寧可回報看不懂，也不會亂猜。

---

### 指定幣別

把幣別代碼寫在金額後面：

```
/add 3000 JPY 拉麵
```

也可以用符號寫，例如 `¥3000`、`€50`、`NT$500`、`3000円`。支援的幣別見 [多幣別](/help/multi-currency)。

沒寫幣別時就用群組的**預設貨幣**。當這筆的幣別和預設貨幣不同時，卡片第一行會附上換算結果（`≈ 660 TWD`）。

---

### 只給某些人分

```
/add 500 晚餐 @alice @bob
```

只會平均分給 alice 和 bob。這裡的 `@` 只能指定**已經在帳本裡**的人；找不到的話機器人會直接告訴你，不會猜。

還沒進帳本的人，見[群組與成員](/help/group-management#誰會自動加入帳本)怎麼把他加進來。

---

### ☰ 調整：記完之後再改

點「**☰ 調整**」會展開這些選項：

| 按鈕         | 作用                                                      |
| ------------ | --------------------------------------------------------- |
| **誰付**     | 點名字選一位，把這筆改成他付的（只有單一付款人時會出現）  |
| **誰分**     | 點名字打勾／取消，另有「全選」和「只有我」                |
| **份數**     | 每人一列 ⊖ / ⊕ 按鈕，加減這個人的份數，另有「重設為均分」 |
| **幣別**     | 從常用幣別挑，或按「其他…」自己輸入                       |
| **± 金額**   | 改這筆的總金額                                            |
| **App 編輯** | 跳到 Mini App 做更細的設定                                |
| **← 收起**   | 收起選單（每次點選都已經存好，不用按這顆才存）            |

「份數」適合有人吃兩人份的情況——按一下 ⊕ 設成 ×2，就會分到兩倍。目前的份數顯示在卡片上（`・小明 ×2 400`）。

> 如果這筆是在 App 裡用「指定」「比例」「調整」模式設定過的，**誰分**和 **份數**不會出現——那些模式帶有逐人的金額意圖，用按鈕改會把它壓平。卡片會提示你改用「App 編輯」。這時候按 ± 金額，各人金額會**依比例**跟著縮放，不會被打回均分。
>
> 同理，如果這筆是**多人共付**（在 App 裡設了好幾位付款人），**誰付**也不會出現，因為按鈕只能指定一個人，會把其他人的墊付金額弄丟。要改請用「App 編輯」。

按鈕沒有時效，舊訊息的卡片隨時都能再點；每次點都是重新讀資料庫再畫一次，多個人同時點也不會打架。

---

### 附收據照片

**傳照片時在說明欄打指令**——選好照片，在說明（caption）欄輸入 `/add 480 超市採購` 送出，支出和收據一次完成。這條路徑和純文字 `/add` 完全一樣，`@` 指定對象和 ☰ 調整 按鈕都能用，只有**一次傳多張的相簿**不支援。

**事後補傳**——點卡片上的「**⊕ 收據**」，機器人會請你回覆並附上照片。

> 機器人流程每筆支出只存**一張**收據。要放多張請到 Mini App 或網頁版編輯這筆支出，最多 **5 張**。每張 10 MB 以內，JPG、PNG 或 WebP。

---

### 打錯了怎麼辦

金額看不懂或格式不對時，機器人會回報錯誤，並且**附上一個可以直接回覆的提示框**（「👇 回覆這則重打」），重打一次就好，不用重新輸入 `/add`。按 **± 金額** 或 **其他…** 後回覆了看不懂的值，也會再問一次。

只打 `/add` 不帶參數也會跳出提示框，直接回覆「金額 說明」就好。

> **一次記一筆。** 送出多行訊息時，機器人會請你一次記一筆，誰分、份數記完再用 ☰ 調整 改。

---

### 在私訊記帳

在跟機器人的私訊裡打 `/add 500 晚餐` 也能記帳：

- 你只在一個群組：直接記到那個群組。
- 你在好幾個群組：機器人會問「要記到哪個群組？」，點群組名稱就記好。

記好後，群組裡照樣會出現這筆的卡片，私訊裡則回一則「✓ 已記到「群組名稱」」和明細，附 **App 編輯** 和 **⊗ 刪除**。要用 ☰ 調整 請到群組裡的卡片。

私訊裡的 `@` 只能指定**已經在帳本裡**的人。

---

## 用圖形介面記帳（完整選項）

在 Mini App 或網頁版的群組主頁，點「紀錄」區塊右上角的「**＋ 支出**」。欄位由上到下是：

### 金額與幣別

輸入金額並選幣別，預設為群組的預設貨幣。

### 匯率

只有在**這筆的幣別和群組預設貨幣不同**時才會出現，標示為「匯率（1 XXX = ? YYY）」。欄位空著時，灰字會顯示目前套用的匯率和來源，例如「0.22（當日市場匯率）」或「0.21（群組自訂匯率）」；下方顯示換算後的金額（`≈ 660 TWD`）。你可以直接填入自己談好的匯率，這筆就會鎖定用它換算。詳見 [多幣別](/help/multi-currency)。

### 日期

預設今天，可改成過去的日期。這個日期也決定要用哪一天的市場匯率。

用 `/add` 記的支出會記在**群組時區的今天**（預設台北時間，可以改，見[群組時區](/help/group-management#群組時區)）。

### 說明

選填，最多 500 字。

### 收據

點「**附上收據照片**」選取，最多 5 張。點縮圖可放大，也能逐張移除。

### 付款人

預設是你自己。多人共付時點「**新增付款人**」切換成多人模式，勾選付款的人並分別填金額。下方會即時顯示「已付 X / 總額」，**加總必須等於總金額**才能儲存。要回到一個人付全額，點右上的「**改回一人付款**」。

### 分帳方式

| 方式     | 你要輸入什麼           | 怎麼算                                                     |
| -------- | ---------------------- | ---------------------------------------------------------- |
| **均分** | 不用輸入               | 所有參與者平均分，餘數逐分分配                             |
| **指定** | 每人的金額             | 直接採用，加總需等於總金額                                 |
| **比例** | 每人的百分比           | 依比例換算，加總需為 100%                                  |
| **份數** | 每人的份數             | 依份數比例分配，留空預設 1 份                              |
| **調整** | 每人**額外**負擔的金額 | 先扣掉所有額外金額，剩下的平均分，再各自加回自己的額外金額 |

「調整」適合「大致均分，但某幾個人要多付一點」——例如某人多點了一份甜點，就在他那列填甜點的錢，其餘餐費照樣平分。額外金額的加總不能超過總金額。

> 用「均分」和「份數」記的支出，之後在機器人卡片上仍然可以用 誰分 / 份數 調整；用「指定」「比例」「調整」記的則只能在 App 裡改。

### 參與者

勾選誰要分擔。暫停分帳的成員仍會出現在清單裡，只是預設不勾選。下方狀態列會即時顯示加總是否平衡（「還差」或「超出」多少），不平衡無法儲存。

---

## 每筆紀錄在群組裡都有一則訊息

不管是用 `/add` 記的，還是在 Mini App、網頁版記的，**每一筆紀錄都會在 Telegram 群組裡有一則專屬訊息**，而且從頭到尾都是同一則：

| 動作     | 群組裡會發生什麼                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------- |
| **新增** | 貼出一則訊息——支出是完整的卡片（含 ☰ 調整 / ⊕ 收據 / ⊗ 刪除 按鈕），還款是「💸 還款　金額」加上「A → B」 |
| **修改** | **就地編輯同一則訊息**，不會再貼一則新的                                                                  |
| **刪除** | 訊息改寫成劃掉的「🗑 ~~說明　金額~~」並**留在群組裡**，不會消失                                            |

所以在 App 裡改了金額，群組裡那張卡片會自己跟著更新；大家不用切到 App 也知道帳目變動了。

> 在 App 記的支出，群組卡片和 `/add` 記出來的**完全一樣**——一樣可以點「☰ 調整」改誰付、誰分、份數、幣別。兩種記法之後的操作沒有差別。

還款的訊息比較簡單，只有「App 編輯」和「⊗ 刪除」兩顆按鈕，因為還款沒有份數、參與者這些可調的東西。

> 這些訊息**一律靜音**，不會發出通知音效。另外，如果有人正把某張卡片的「☰ 調整」選單打開著，而這筆紀錄剛好被人在 App 裡改了，選單會收合回一般的卡片檢視——那是預期行為，選單只是畫面狀態，不屬於紀錄本身。

## 修改或刪除

在群組主頁的清單點任一筆，會**直接進入編輯頁**（沒有另外的詳情頁），所有欄位都能改，存檔後餘額立即重算。

**群組裡的任何成員都可以修改或刪除任何一筆支出**，沒有「只有記錄的人才能改」這種限制。

這是刻意的設計：常見情況是「A 把 800 打成 300，而 B 就站在旁邊」——如果鎖住，B 只能等 A 有空處理，但 A 可能在睡覺、在開車，甚至已經退出群組了。

取而代之的是**留下痕跡**：

- 編輯頁的刪除按鈕旁邊會標示「**由 X 於 ⟨時間⟩ 記錄**」
- 這筆被改過的話，下面還會多一行「**最後由 Y 於 ⟨時間⟩ 修改**」，點下去就是這筆的完整變更紀錄
- 刪除別人記的東西時，確認對話框會寫明這筆是誰記的
- 用機器人的 ⊗ 刪除，訊息會被改寫成劃掉的「⟨說明⟩　⟨金額⟩」，下一行寫「X 記錄 · Y 刪除」，群組聊天室本身就是稽核紀錄

> 如果同時有兩個人開著同一筆在編輯，其中一個人先刪掉了，另一個人再按刪除會看到「這筆支出已經不在了，可能剛剛被其他人刪除」——這是正常的，不是錯誤。

## 動態紀錄

每一次新增、修改、刪除都會被記下來：誰做的、什麼時候、改了什麼、原本是多少。

從**群組設定 → 動態紀錄**可以看整個群組的流水；從某一筆的編輯頁點「最後由 … 修改」則只看那一筆的歷史，最舊的「建立」在最下面，所以捲到底就知道它原本長什麼樣。按左上的「返回」會回到你剛才來的地方：從編輯頁進來就回編輯頁，從群組動態進來就回群組動態。已刪除的紀錄在群組動態裡也點得進去，可以看是誰刪的。群組動態上方可以用「全部／手動記錄／透過應用程式」篩選；透過[連結的應用程式](/help/mcp)記下的改動，頭像會有角標，名字後面也會註明是透過哪個應用程式。

| 你會看到               | 說明                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| **新增了 ⟨說明⟩**      | 誰記的，金額與分帳人數                                           |
| **改了 ⟨說明⟩**        | 哪些欄位動了，以及每個欄位的前後值（例如「金額 1,200 → 1,600」） |
| **刪除了 ⟨說明⟩**      | 刪掉的是什麼、原本由誰記的                                       |
| **鎖定了 ⟨幣別⟩ 匯率** | 群組匯率變更時一次影響了幾筆                                     |

已經被刪掉的紀錄，歷史仍然保留得住——這正是這份紀錄存在的意義。

> 機器人 **不會**為了改動另外發訊息到群組。那筆紀錄原本的那則訊息會就地更新成最新的值，想知道「原本是多少、誰改的」就到動態紀錄看。
