# 加到主畫面

把揪帳的網頁版加到手機主畫面，桌面上就會多一個揪帳圖示，點了直接全螢幕打開，不用再找瀏覽器分頁。**不用下載任何東西**，也不佔手機空間。

加到主畫面之後，才能在 iPhone 上收到揪帳的推播通知。

> 這一頁講的是網頁版。Telegram 裡的 Mini App 不需要加到主畫面。

---

## iPhone、iPad

要用 **Safari** 打開揪帳網頁版。LINE、Telegram 裡的內建瀏覽器沒辦法加到主畫面，請先改用 Safari 開啟同一個網址。

1. 點網址列旁的 **⋯**，再點 **分享**。
   - 如果畫面下方直接看得到分享鈕（方框加向上箭頭），點它就好。Safari 的「設定 → App → Safari → 分頁」選了「底部」或「頂部」，或 iOS 18 以前，分享鈕會直接在工具列上。
2. 往下滑，點 **加入主畫面**。
3. 「以網頁 App 打開」保持開啟，右上角點 **加入**。
4. 回到桌面，點揪帳圖示打開，**再登入一次**。

> 主畫面上的揪帳跟 Safari 不共用登入狀態，所以第一次打開要再登入一次。之後就會一直保持登入。

在網頁版的 **個人設定 → 主畫面捷徑** 點「怎麼加」，也看得到同樣的步驟。

## Android

用 **Chrome** 打開揪帳網頁版：

1. 到 **個人設定 → 主畫面捷徑**，點「加入」。
2. Chrome 會跳出確認視窗（上面可能寫「安裝」，這是 Chrome 的用字），點確認。

沒看到「加入」按鈕的話，也可以點 Chrome 右上角的 **⋮**，選 **加到主畫面**。

Android 上加到主畫面跟 Chrome 共用登入，不用再登入一次。

## 電腦

Chrome 和 Edge 也能把揪帳裝成電腦上的一個視窗：點網址列右邊的安裝圖示，或到 **個人設定 → 主畫面捷徑** 點「加入」。

---

## 怎麼移除

跟移除其他 App 一樣：在主畫面長按揪帳圖示，選移除。你的帳和群組都存在伺服器上，移除捷徑不會刪掉任何資料。

---

## 推播通知

開了通知，朋友記了跟你有關的帳，手機會直接跳出提醒，不用一直點開來看。

### 會通知什麼

只通知**跟你有關**、而且**不是你自己做的**改動：

- 別人記了一筆你要分攤、或記你付錢的費用（內容會寫你分多少）
- 別人記了一筆你收到或付出的還款
- 你在上面的紀錄被別人修改或刪除
- 你記的紀錄被別人修改或刪除

點通知會直接打開那一筆。被刪掉的紀錄會打開它的動態紀錄。同一筆紀錄短時間內被改好幾次，只會留下最新的一則通知。

### 怎麼開

1. iPhone、iPad 要先照上面的步驟**加到主畫面**，並從主畫面打開揪帳（需要 iOS 16.4 以上）。Android 和電腦直接在瀏覽器裡就能開。
2. 到 **個人設定 → 通知**，打開「這台裝置的推播」。
3. 系統詢問時選 **允許**。
4. 點「傳送測試通知」確認收得到。

開關只管**這一台裝置**。手機和電腦都想收，就在兩邊各開一次。

打開揪帳時，群組頁上方也可能出現「把揪帳加到主畫面？」或「朋友記了你要分的帳時通知你？」的卡片，按鈕的作用一樣。選「下次再說」一週後會再問（最多三次），選「不要再問」就不會再出現。

### 只想關掉某個群組

到該群組的 **群組設定 → 通知**，關掉「推播這個群組的紀錄」。只影響你自己，其他成員照常收到。

已連結 Telegram 的群組，群組訊息本身就會提醒你。不想同一件事收到兩次，可以把這個群組的推播關掉。

### 不小心按了「不允許」

網頁沒辦法再問一次，要自己去設定打開：

- **iPhone**：設定 → 通知 → 揪帳 → 允許通知
- **Android Chrome**：網址列左邊的圖示 → 權限 → 通知
- **電腦 Chrome／Edge**：網址列左邊的圖示 → 網站設定 → 通知

改好之後回到 **個人設定 → 通知**，把開關打開。

> Telegram 裡的 Mini App 沒有推播通知，Telegram 的群組訊息已經會提醒你。
